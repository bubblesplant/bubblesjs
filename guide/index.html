指南 ​

通过 create-bubbles 创建 Vue、React、Taro、Next.js 或全栈项目，也可以进入 Electron 脚手架创建桌面应用。

  • 快速开始：准备环境、创建项目并启动开发。
  • 模板总览：对比模板，查看各自的配置、开发与构建命令。
  • 工具包：在现有项目中使用 BubblesJS 的请求库、工具函数和 Vue 组件，安装、示例与 API 都在各包页面中。
