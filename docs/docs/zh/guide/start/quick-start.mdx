# 快速开始

## 环境要求

在开始之前，请确保你的开发环境满足以下要求：

- **Node.js**: 版本 18 或更高版本
- **包管理器**: npm、yarn、pnpm 或 bun

## 创建 BubblesJS 项目

使用 `create-bubbles` 脚手架工具来创建一个新项目：

import { Tabs, Tab } from '@rspress/core/theme';

<Tabs>
  <Tab label="npm">
    ```bash
    npm create bubbles@latest my-project
    ```
  </Tab>
  <Tab label="yarn">
    ```bash
    yarn create bubbles my-project
    ```
  </Tab>
  <Tab label="pnpm">
    ```bash
    pnpm create bubbles@latest my-project
    ```
  </Tab>
  <Tab label="bun">
    ```bash
    bun create bubbles@latest my-project
    ```
  </Tab>
</Tabs>

## 选择模板

运行命令后，会出现交互式提示，让你选择模板：

- **vue-vite-eslint**：Vue 3、Vite、ESLint、Pinia、Ant Design Vue Next
- **react-rsbuild-biome**：React 19、Rsbuild、Biome、Ant Design
- **vp-react**：基于 Vite+ 的 React 起步模板
- **vp-react-shadcn**：集成 shadcn 与 Tailwind CSS 的 Vite+ React 模板
- **vp-monorepo-react-nestjs**：Vite+ monorepo 起步模板
- **taro-vue-eslint**：面向小程序和 H5 的 Taro 4.2 / Vue 3.5 模板
- **nextjs-vinext-eslint**：基于 Vinext 的 Next.js 16 / React 19 模板

## 启动开发服务器

创建完成后，进入项目目录并启动开发服务器：

```bash
cd my-project
```

<Tabs>
  <Tab label="npm">

    npm install
    
    # 启动开发服务器
    npm run dev

  </Tab>
  <Tab label="yarn">

## 项目结构

生成的目录结构取决于所选模板。单应用模板通常包含 `src/`、`public/`、`package.json`，以及 `vite.config.ts` 或 `rsbuild.config.ts` 等构建配置；monorepo 模板会包含 `apps/`、`packages/` 和 `pnpm-workspace.yaml`。
