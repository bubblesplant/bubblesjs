工具包总览 ​

选择一个工具包，查看它的安装方式、使用示例和 API。接口说明统一放在各包页面中。

工具包说明
@bubblesjs/request基于 Alova 的请求封装，支持响应处理、错误处理和双重调用模式。
@bubblesjs/utils对象合并、类型判断与 JSON 解析等工具函数。
@bubblesjs/vue-ai-chartVue 3 AI 聊天组件，支持会话管理、Markdown 和代码高亮。
@bubblesjs/vue-annotationVue 3 文本标注组件，支持实体、关系标注和 Unicode 字素处理。
@bubblesjs/vue-infinite-scrollVue 3 无缝自动滚动组件，支持悬停暂停和速度配置。
