# 万物梦幻主题视觉验证

使用当前本地 React 页面，通过独立 Playwright 浏览器上下文提供虚构数据。不会读取浏览器个人资料、真实凭据或现有登录态，不会写入后端数据。

```powershell
node ".spaces/04.界面与主题/万物梦幻/工具/visual-check.mjs" --base-url http://127.0.0.1:9999
```

- `--check-launch`：只验证本机 Chromium 可启动，不打开页面、不截图。
- `--only companies-mobile-390`：只运行指定场景；`--only companies-mobile` 复验全部手机企业场景。定向运行会更新同一服务地址的已有报告，保留其他场景验证结果。
- `PLAYWRIGHT_MODULE`：覆盖 Playwright 模块位置。
- `PLAYWRIGHT_EXECUTABLE_PATH`：覆盖已有 Chromium 可执行文件位置。
- 若受限沙箱阻止启动 Chromium（`spawn EPERM`），需使用获准的沙箱外执行权限运行同一脚本。

`fixtures.mjs` 定义平台、企业、项目身份以及企业列表空/有数据状态。全部 `/api/` 请求由浏览器路由拦截：只允许已知 GET fixture，写入请求返回 405，未知请求返回 501 并导致验证失败。

输出的 PNG 使用虚构名称“星屿科技”“月光计划”和 `example.invalid` 测试账号。`visual-report.json` 记录通过项和失败项。它们是本地 UI 验证证据，不能作为真实业务数据或服务端集成验证结果。
