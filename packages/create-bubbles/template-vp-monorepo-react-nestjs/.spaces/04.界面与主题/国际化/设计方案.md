# 前端国际化设计方案

## 统一状态

`@bubblesjs/i18n-core` store 是唯一语言状态源。`apps/web/src/i18n/config.ts` 集中维护应用 locale 及其适配标识，`ui-locale.ts` 将应用 locale 映射为：

- antd 的 `Locale` 对象；
- Pro Components 的 `IntlType`（`zhCNIntl` / `enUSIntl`）；
- Day.js locale 标识（`zh-cn` / `en`）；
- `<html lang>` 标识。

## 渲染与副作用

`App.tsx` 在渲染时将 antd locale 和 Pro `intl` 传入 Provider；在 locale 变化后的 effect 中设置 Day.js 全局 locale 和 `<html lang>`。这样静态组件配置会随 React 重新渲染，日期库的全局副作用也只在语言变化时执行。

## 扩展约束

新增语言时必须同时补充词条加载器、`APP_LOCALE_ADAPTERS`、antd locale 包、Pro Components intl 以及 Day.js locale 导入，并执行 `pnpm i18n:check` 与前端构建。
