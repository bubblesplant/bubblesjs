# 前端国际化需求

## 目标

应用语言切换必须由同一份 locale 状态驱动，确保业务词条、Ant Design、Ant Design Pro Components、Day.js 以及文档语言属性同步变化。

## 范围

- 当前支持 `zh_CN`（简体中文）和 `en_US`（English）。
- 切换结果继续由现有 i18n store 持久化。
- Ant Design 组件文案、Pro Components 内置文案和 Day.js 日期/相对时间格式必须与当前语言一致。
- 浏览器 `<html lang>` 必须同步更新。

## 验收标准

1. 初始语言、持久化语言和运行时切换均使用同一 locale 状态。
2. 切换到英文后，antd、Pro Components、Day.js 和 `<html lang>` 均使用英文配置；切回中文后恢复中文配置。
3. 新增语言时只需扩展集中式映射，并能明确补充对应组件库和 Day.js locale。
