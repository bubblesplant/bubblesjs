## 比较版式

每套采用统一宽幅设计板，展示主要指针与手型、八个常用状态、深浅背景以及 32 px 和 48 px 图标画布预览。小尺寸保留主体轮廓，减少面部和装饰细节；放大展示只用于比较造型，不代表实际指针大小。

## 可用性原则

- 指针热点始终对应清晰尖端，装饰不能遮住定位点。
- 轮廓在明暗背景上均可辨识，避免大面积发光、拖尾和颗粒装饰。
- 保持箭头、手型、I 形文本光标、忙碌环和缩放箭头的标准含义。
- 通过柔和阴影、低饱和色和圆润轮廓体现软萌，装饰保持克制。
- 历史图稿只呈现动画关键形态；当前制作 24 帧星轨动画，4 jiffy/帧，约 1.6 秒循环，热点在所有帧保持一致。

## 指针包实现

- 17 个 Windows 角色：正常、帮助、后台运行、忙碌、精确选择、文本、手写、不可用、纵向／横向／两种斜向缩放、移动、候选、链接、位置及人员选择。
- `.cur` 使用标准 32 位 DIB 与透明 AND 蒙版，每个文件包含 32/48/64/96/128 px；`.ani` 使用 RIFF ACON，每帧内嵌单个 128 px 高清 CUR，由 Windows 按实际大小缩放。实测本机原生加载拒绝每帧含多尺寸目录的 ANI，单尺寸帧正常，因此采用兼容编码；证据见 [动画兼容性检查](./测试证据/ani-compatibility.json)。
- 所有图形沿用本地绘制源；新增角色使用相同色板和轮廓语义。主箭头及链接手型保持原有造型，热点位于箭头尖端与食指端，文本和缩放热点位于中心。
- 预览从生成后的实际 DIB 帧解码，展示完整角色、深浅背景和原尺寸；另提供动态 GIF 便于观看。
- 安装只修改当前用户的鼠标设置，先备份原值；文件复制到当前用户的本地应用数据目录，不依赖解压目录长期存在。恢复工具还原备份并刷新系统指针。
- 刷新使用明确的 `SystemParametersInfoW(SPI_SETCURSORS, 0, NULL, 0)`；注册表已单独持久化，无需此调用再次写入配置。本机实测旧 flags=3 返回失败且错误码为 0，flags=0 成功，A/W 均表现一致，根因不是中文路径编码。原生包装层立即捕获错误码，错误码为 0 时说明系统未提供原因。
- 回滚分别处理注册表恢复与即时刷新，任何回滚错误均保留初始安装错误。按用户已执行安装的意图进行真实安装、恢复及回滚验证，最后应用棉花云朵；不修改元气桌面缓存。
- 真实运行 Windows PowerShell 5.1 安装器并比较 17 个角色路径、文件哈希、原值类型及存在性；故障注入只在独立测试子进程替换原生接口。核心 5 个共享系统指针的 7 个画面与安装文件原生绘制、热点完全一致。工具为 [安装运行验证](./工具/cloud-installer-verify.ps1) 和 [系统指针对照](./工具/cloud-active-cursor-check.py)。
- 原生绘制使用 `DrawIconEx` 在内存画布验证明暗背景；24 个静态组合与独立解码合成结果的最大通道差不超过 3/255。文件保持直通 BGRA，由 Windows 加载器处理透明度，避免重复预乘。
- 制作工具为 [cloud-build.py](./工具/cloud-build.py)，原生绘制工具为 [cloud-native-preview.py](./工具/cloud-native-preview.py)。压缩包与使用入口见 [交付记录](./交付记录.md)，验证边界见 [测试报告](./测试报告.md)。
