## 首轮历史绘制规格

最终图稿采用 Pillow 本地绘制，生成工具见 [preview-render.py](../工具/preview-render.py)。A/B/C 使用抗锯齿图形、轻微纵向渐变及明暗双层轮廓；D 使用 24×24 像素网格和最近邻缩放。八个状态固定为正常选择、链接选择、文本选择、忙碌、后台运行、移动、缩放和不可用。所有方案采用相同版式，提供放大造型、深浅背景及 32 px 图标画布的基准预览。

首次内置图片工具尝试的方向摘要为白色、深色轮廓的 Windows 鼠标方案预览，包含常用状态与深浅背景对比。该工具未返回可保存图片，最终交付以本地绘制规格为准，未使用 CLI/API 回退。

32 px 指图稿内的图标画布尺寸；阅读时须以原图 100% 比例查看。应用缩放、显示器 DPI 与将来的系统指针大小会影响实际观感。图稿中的忙碌／后台运行只展示静态形态，尚未制作动画。
