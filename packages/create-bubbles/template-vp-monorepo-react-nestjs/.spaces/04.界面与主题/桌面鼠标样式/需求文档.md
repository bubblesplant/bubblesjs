## 背景与目标

用户正在使用元气桌面的动态主题，壁纸与鼠标已经生效，认为当前 mouse 鼠标样式不够美观，要求重新设计并先提供几套 UI 图片供选择。

用户认为首轮四套均不好看，并明确选择“可爱软萌”。本轮应通过角色轮廓、圆润线条和柔软质感建立差异，避免仅对普通箭头更换颜色。

## 范围与约束

- 当前阶段将已选定的③棉花云朵制作成 Windows 指针包；①奶油小猫、②桃桃兔子保留为未选方案。
- 补齐 Windows 17 个常用指针角色，忙碌与后台运行采用星轨动画，保持整套形状与配色一致。
- 预览同时考虑深浅背景上的辨识度，箭头尖端明确，文本插入光标简洁。
- 制作多尺寸 `.cur` 与 `.ani`、安装及恢复工具、压缩包；另提供从实际指针文件还原的预览，明确区分概念图和实际资源。
- 不覆盖现有 mouse 目录，不修改应用的前后端业务代码。本次按用户安装意图修复并实际应用所选指针，保留首次原配置备份。
- 图稿、设计说明和交付记录统一归档在本功能目录，图片保存在 `ui/`。

## 验收标准

1. 指针包与选定的「棉花云朵」造型一致，涵盖 Windows 17 个常用角色。
2. 静态指针提供 32、48、64、96、128 px 资源；两种动画循环平顺、热点固定。
3. 验证文件结构、全部尺寸热点、动画时序以及 Windows 原生加载，提供真实文件预览。
4. 安装工具先备份原配置并提供恢复入口；实际验证立即应用、恢复及失败回滚，重复安装保留首次备份。刷新失败时报告真实系统错误，回滚失败不得遮盖安装错误；不覆盖元气桌面缓存。

## 待确认事项

- 无阻塞事项。默认制作标准大小与适配高 DPI 的多尺寸资源，星轨动画采用约 1.6 秒循环。
- 系统即时应用已验证；元气桌面以后换主题是否重新覆盖系统指针取决于其主题设置。
