# 棉花云朵鼠标

雾紫云朵、冰白填充和星月点缀，覆盖 Windows 的 17 个常用指针角色。忙碌与后台运行采用 24 帧、约 1.6 秒的星轨循环动画。静态文件内置 32、48、64、96、128 px 五种尺寸；动画使用 128 px 高清帧，由 Windows 按实际大小缩放。

## 安装

1. 将压缩包完整解压到任意文件夹。
2. 双击 **安装.cmd**。鼠标会立即切换到棉花云朵，不需要管理员权限。
3. 原鼠标配置会先备份，资源复制到 `%LOCALAPPDATA%\CottonCloudCursors`。安装成功后可以移动或删除原解压文件夹。

如果从当前工作区直接使用，打开同目录的 **安装.cmd** 即可，无需重复解压。

## 恢复

双击 **恢复原鼠标.cmd** 即可恢复首次安装前的鼠标设置。若已删除解压目录，到 `%LOCALAPPDATA%\CottonCloudCursors` 找到同名文件双击。

重复安装不会覆盖首次备份；恢复工具保留备份与安装资源。安装失败时会还原本次安装前的设置。

2026-10-14 已修复 Windows 刷新失败问题。如果之前解压的入口仍报“Windows 未能刷新鼠标指针”，请使用更新包中的入口或当前工作区入口。原备份会继续保留；若即时刷新仍失败，提示会说明原配置是否还原，并显示系统错误原因。

## 大小与元气桌面

- 可在 Windows「设置 → 辅助功能 → 鼠标指针和触控」调整指针大小；显示器缩放也会影响画布选择。
- 该包直接使用 Windows 系统指针设置。元气桌面若在换主题时再次应用原鼠标，需要关闭其主题鼠标同步，或重新运行安装入口。
- 不会覆盖元气桌面的缓存，也不会改变壁纸。
- 本包已检查文件结构、热点、动画及 Windows 原生加载，并在本机实际验证安装、恢复、重复安装和失败回滚；系统核心角色的绘制及热点与安装文件一致。

## 文件

- `cursors/`：15 个静态 CUR 和 2 个动画 ANI。
- `manifest.json`：角色顺序及文件校验值。
- `manage.ps1`：当前用户安装、恢复和只读校验逻辑。
- `安装.cmd`、`恢复原鼠标.cmd`：双击入口。
