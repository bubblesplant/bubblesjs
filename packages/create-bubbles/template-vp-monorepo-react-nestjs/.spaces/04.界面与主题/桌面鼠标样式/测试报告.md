## 兼容性结论

本机 Windows 拒绝每帧带多尺寸 CUR 目录的 ANI；单尺寸帧可正常加载并按请求尺寸缩放，见 [兼容性实验](./测试证据/ani-compatibility.json)。最终使用单个 128 px 高清帧，17 个角色均完成五种请求大小的原生加载检查。透明度使用直通 BGRA；Windows 实际绘制与独立合成匹配，避免重复预乘。

## 验证边界

- Win32 加载和绘制仅作用于内存，资源使用后释放；不触发系统设置刷新。
- 上一阶段只读检查未运行安装，用户随后遇到刷新失败。本次对 A/W 入口实测：flags=3 均返回 false 且错误码 0，flags=0 均返回 true。安装器改用明确 W 入口、flags=0；此调用从已写入的注册表重载资源。
- 实际安装、恢复与重复安装均运行成功，最后保持棉花云朵已应用。三种错误分支采用独立进程模拟原生失败，注册表写入和回滚仍为真实操作；不把模拟错误称为系统自然发生的错误。
- 未修改元气桌面缓存，尚未验证实际桌面换主题后的覆盖行为。
- 未修改前后端业务代码，不运行应用测试。

可重复制作与资源验证工具为 [cloud-build.py](./工具/cloud-build.py)，原生绘制工具为 [cloud-native-preview.py](./工具/cloud-native-preview.py)；安装运行检查为 [cloud-installer-verify.ps1](./工具/cloud-installer-verify.ps1)，即时应用检查为 [cloud-active-cursor-check.py](./工具/cloud-active-cursor-check.py)。运行安装验证会真实切换鼠标并最终应用棉花云朵。
