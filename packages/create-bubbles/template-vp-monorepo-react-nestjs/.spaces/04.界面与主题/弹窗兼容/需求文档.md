# 弹窗兼容需求文档

状态：当前有效需求；2026-10-15 三处配置已迁移，定向检查、Web 类型检查及现有密码与选择器 24 项测试通过；未执行真实浏览器遮罩点击验证，详见[测试报告](./测试报告.md)。

## 目标与范围

消除 Ant Design Modal 的 `maskClosable` 弃用警告，将 Web 中三处配置迁移为 `mask.closable`：本人修改密码、管理员重置密码、基础表格选择器。

## 行为与设计

- 两个密码表单通过 `modalProps.mask = { closable: false }` 禁止点击遮罩关闭，保留现有取消、关闭及提交保护逻辑。
- 表格选择器使用 `mask = { closable: !confirming }`，空闲时允许点击遮罩关闭，确认提交期间禁止关闭。
- 沿用现有组件和 `show()`／`hide()` 调用方式；接口、权限、数据与会话规则保持现行契约。
- 当前依赖为 antd 6.6.6、Pro Components 3.1.14-7；ModalForm 直接透传 `modalProps`，无需新增兼容封装或调整依赖。

## 验收标准

1. Web 业务源码不再传入 `maskClosable`，三个弹窗均使用受当前 antd 类型支持的 `mask.closable`。
2. 密码表单遮罩保持不可关闭，选择器遮罩关闭能力继续随确认状态切换。
3. 执行受影响文件检查、Web 类型检查及现有密码与选择器测试；记录实际结果与运行态未覆盖边界，见[测试报告](./测试报告.md)。
