# Vue 版本对齐设计

状态：当前有效。更新日期：2026-11-17。组件库固定版本已实施；业务、代理修复、静态视觉及路由转场方案已实施，2026-11-16 的 29 项原生浏览器转场专项通过，验证范围见[测试报告](./测试报告.md)。

## 实现约定

- Vue 3 + Vue Router + Pinia；Alova Vue 适配器管理请求，BubblesJS i18n 提供响应式翻译。
- 复用 `shared/types`、`shared/utils` 中的作用域路径、页面目录和权限判断，不复制服务端契约。
- 页面按业务分目录；列表、业务弹窗和专用 API 集中在对应功能目录。通用基础设施限于鉴权、空间请求、表格及表单适配。
- UI 直接参照 React 当前实现：使用“万物”文字和珍珠星环品牌，主色 `#7864c4`、文字 `#302b49`、画布 `#f5f3fc` 及冰蓝／粉紫氛围背景；正文沿用系统中文字体，品牌与认证大标题沿用 React 的系统宋体。以功能样式文件管理认证、工作台、空间卡片和管理面板，避免大文件反复覆盖。
- 登录／注册采用 React 的品牌叙事区与玻璃表单双列结构，表单宽 456px、卡片圆角 28px、输入高 46px；移动端隐藏大幅装饰并保持品牌、表单和语言切换可用。
- 工作台对齐 72px 玻璃顶栏、品牌、当前空间切换控件、侧栏选中态及内容留白；空间入口对齐类型分区和卡片，管理页使用统一 18px 玻璃面板、浅紫表头和工具栏。窄屏使用导航抽屉，表格内部横向滚动。
- 组件库固定为 `@bubblesjs/antdv-next-pro@0.3.5`，依赖声明与独立工作区锁文件同步更新；通过具名导入使用真实组件 API，入口加载 reset 和库样式。
- 工作空间和页面组件使用不同的身份键，旧页面卸载后取消请求；服务端拒绝授权后刷新权限并阻止旧数据继续展示。
- 组织与岗位分配复用共享有效性判断：失效的既有组织关系只可保留或降级职责，不可升级；停用成员、组织或岗位不可新增关系。读取失败时禁止提交全量替换。

## 技术契约

路由转场使用浏览器 View Transition 快照，不保留出场业务组件。鉴权与懒加载完成后的 `beforeResolve` 捕获旧画面，在快照更新回调中放行导航，并等待对应 `afterEach` 与 Vue `nextTick` 提交 DOM 后捕获新画面。快照更新期间不能等待 `requestAnimationFrame`，否则浏览器暂停渲染会使更新超时并跳过动画。新导航跳过前次动画并释放等待；取消、错误与动画异常均释放导航，不影响原权限守卫。

根出口提供整页快照边界；现有 `.workspace-body` 提供内容边界，保留表格的直接父子关系。同空间身份由路由作用域判断；同示例布局为内容切换，其余为整页切换。导航期间仅启用一个具名边界，结束后移除许可，页内更新不会触发。内容区沿用 React 的 320ms `cubic-bezier(0.4, 0, 0.2, 1)`，整页沿用 500ms `cubic-bezier(0.45, 0, 0.55, 1)`；旧快照向左移出、新快照从右移入，禁用 root 默认动画并裁剪快照组。首次导航、减少动态效果及 API 不可用时直接导航。

后端保持现行接口。认证使用 `/auth/login`、`/auth/register`、`/auth/me`、`/auth/logout`、`/auth/change-password`；空间使用 `/workspaces` 与对应作用域 `/access`。其余接口依据 React 各功能 `api.ts` 及共享 DTO 对齐。列表返回 `PageResult<T>`，请求分页字段为 `page`、`pageSize`、`query`，在 ProTable 请求边界转换 `current`。需要并发控制的操作提交记录的 `expectedVersion`。菜单按服务端可见路由和权限生成。

本地开发统一由 `VITE_API_URL` 指向现有 NestJS，Vue 的 `.env.development` 默认使用与 React `.env.dev`、服务端 `PORT` 一致的 13000 端口。浏览器仍请求同源 `/api`，开发代理去除前缀后转发。特定环境可通过未入库的 `.env.development.local` 覆盖；本次不调整生产配置或认证接口。

## 验证

验证类型与生产构建、权限及空间隔离、登录与直达路由、主要管理列表与表单、中文英文及窄屏。19 项转场单测已通过，包含快照更新不等待动画帧的回归；29 项原生浏览器转场专项全部通过，覆盖 500ms 整页与 320ms 内容动画、页面更新不重播、快速导航、取消、降级及历史导航，工具与结果入口见[测试报告](./测试报告.md#2026-11-16-路由转场专项)。浏览器使用虚构接口数据验证交互，不代表真实后端全链路验证。

## 当前实现

- [路由目录](../../../apps/web-vue/src/router/modules/index.ts)对应共享页面目录，共 25 个管理路由与 4 个组件示例；菜单与直达路由使用服务端授权状态。
- [用户状态](../../../apps/web-vue/src/store/modules/user.ts)仅在内存维护身份和空间授权。[空间请求控制](../../../apps/web-vue/src/utils/request/workspace.ts)按空间与会话隔离请求，取消旧请求并抑制迟到响应回写。
- [表单适配](../../../apps/web-vue/src/components/management/SchemaDialog.vue)为每个表单实例分配独立名称，避免 ProTable 搜索字段与弹窗表单产生重复 ID；保存期间禁止重复提交。
- [候选选择器](../../../apps/web-vue/src/components/selector/CandidateSelect.vue)支持远程搜索、分页、选中对象回显及禁选原因；全量关系加载失败时不允许用部分数据覆盖原关系。
- [共享关联规则](../../../packages/shared/src/utils/organization/assignment.ts)统一判断组织、岗位与成员有效性；新增关联与职责升级在提交时再次验证。切换对象或卸载弹窗时，使旧请求结果失效。
- 字典沿用共享输入校验与版本约束，保留历史值并提供内存缓存；组织模板支持层级定义、移动防循环、岗位定义、默认项及版本更新。
- UI 截图与验证工具归档在本功能目录，见[交付记录](./交付记录.md)。构建存在分包体积提示，尚未进行真实后端联调。
- 认证、品牌、应用控件、空间卡片、工作台与管理表面样式按功能拆分。导航使用 React 现有的本地 SVG 资源；表格搜索标签自适应，表体填满工作区并在内部滚动。
- 企业成员按权限读取当前页的组织／岗位快照，展示完整账号、成员及账号状态、角色、组织、岗位与加入时间。新增快照查询复用已有接口，无组织读取权限时不发出请求。
- 语言弹层支持当前语言聚焦、方向键、Escape 与外部焦点收起；桌面侧栏收起时菜单同步折叠，手机抽屉保留完整导航。空间过滤和刷新缩页后同步修正当前页码。
- 移动导航抽屉使用 Antdv Next 当前的 `size` 参数控制宽度，保持 260px；开发模式日志中的 ResizeObserver 通知与生产预览结果分别记录。
- [转场协调](../../../apps/web-vue/src/router/transition/index.ts)与[动画样式](../../../apps/web-vue/src/router/transition/transition.css)已接入应用根出口及路由守卫；`afterEach` 只等待 `nextTick`，快照更新不依赖动画帧。19 项单测及 29 项原生浏览器专项通过，整页和内容区均记录到正确时长、方向与完成状态。
