# Vue 版本对齐设计

状态：当前有效。日期：2026-11-14。已按本方案实现，本地验证结果见[测试报告](./测试报告.md)。

## 实现约定

- Vue 3 + Vue Router + Pinia；Alova Vue 适配器管理请求，BubblesJS i18n 提供响应式翻译。
- 复用 `shared/types`、`shared/utils` 中的作用域路径、页面目录和权限判断，不复制服务端契约。
- 页面按业务分目录；列表、业务弹窗和专用 API 集中在对应功能目录。通用基础设施限于鉴权、空间请求、表格及表单适配。
- UI 以 React 当前梦幻主题为基线：浅色画布、蓝紫强调色、清晰标题层级和侧栏；管理内容左对齐，窄屏侧栏收起，表格横向滚动。保留系统中文字体；不额外引入装饰字体或图片。
- 通过具名导入使用 `@bubblesjs/antdv-next-pro` 的真实组件 API，入口加载 reset 和库样式。
- 工作空间和页面组件使用不同的身份键，旧页面卸载后取消请求；服务端拒绝授权后刷新权限并阻止旧数据继续展示。
- 组织与岗位分配复用共享有效性判断：失效的既有组织关系只可保留或降级职责，不可升级；停用成员、组织或岗位不可新增关系。读取失败时禁止提交全量替换。

## 技术契约

后端保持现行接口。认证使用 `/auth/login`、`/auth/register`、`/auth/me`、`/auth/logout`、`/auth/change-password`；空间使用 `/workspaces` 与对应作用域 `/access`。其余接口依据 React 各功能 `api.ts` 及共享 DTO 对齐。列表返回 `PageResult<T>`，请求分页字段为 `page`、`pageSize`、`query`，在 ProTable 请求边界转换 `current`。需要并发控制的操作提交记录的 `expectedVersion`。菜单按服务端可见路由和权限生成。

## 验证

验证类型与生产构建、权限及空间隔离、登录与直达路由、主要管理列表与表单、中文英文及窄屏。浏览器可使用虚构接口数据验证交互，但不得将此报告为真实后端全链路验证。

## 当前实现

- [路由目录](../../../apps/web-vue/src/router/modules/index.ts)对应共享页面目录，共 25 个管理路由与 4 个组件示例；菜单与直达路由使用服务端授权状态。
- [用户状态](../../../apps/web-vue/src/store/modules/user.ts)仅在内存维护身份和空间授权。[空间请求控制](../../../apps/web-vue/src/utils/request/workspace.ts)按空间与会话隔离请求，取消旧请求并抑制迟到响应回写。
- [表单适配](../../../apps/web-vue/src/components/management/SchemaDialog.vue)为每个表单实例分配独立名称，避免 ProTable 搜索字段与弹窗表单产生重复 ID；保存期间禁止重复提交。
- [候选选择器](../../../apps/web-vue/src/components/selector/CandidateSelect.vue)支持远程搜索、分页、选中对象回显及禁选原因；全量关系加载失败时不允许用部分数据覆盖原关系。
- [共享关联规则](../../../packages/shared/src/utils/organization/assignment.ts)统一判断组织、岗位与成员有效性；新增关联与职责升级在提交时再次验证。切换对象或卸载弹窗时，使旧请求结果失效。
- 字典沿用共享输入校验与版本约束，保留历史值并提供内存缓存；组织模板支持层级定义、移动防循环、岗位定义、默认项及版本更新。
- UI 截图与验证工具归档在本功能目录，见[交付记录](./交付记录.md)。构建存在分包体积提示，尚未进行真实后端联调。
- 移动导航抽屉使用 Antdv Next 当前的 `size` 参数控制宽度，保持 260px；开发模式日志中的 ResizeObserver 通知与生产预览结果分别记录。
