## 2026-11-16 登录故障回归

状态：代理故障修复并通过回归。用户反馈 Vue 无法登录而 React 可登录。根因是 Vue `.env.development` 指向未监听的 8080，当前 NestJS 与 React 使用 13000。修复前实际 Vue `/api/auth/me` 返回 502；修改目标端口后，正在运行的开发服务器已重新加载配置。

- 2026-11-14 验证未连接真实 NestJS、数据库、Redis 或其他外部服务。浏览器写操作多数模拟成功，字典使用内存状态支持回读；这不能证明真实持久化、事务、审计或接口集成已验收。2026-11-16 追加的真实 NestJS 未认证请求探测范围见上节。

- 本轮生产构建成功，但 SchemaForm 分包约 764.64 kB，触发部分分包超过 500 kB 的提示；未进行专项包体优化。完整 `vp check` 仍受既有生成文件格式问题影响，独立类型、ESLint 与不含格式的检查通过。
- 浏览器验证使用本机 Chromium 与模拟移动视口，未覆盖真实触屏设备及其他浏览器。
- 早期开发服务器日志出现过 `ResizeObserver loop completed with undelivered notifications` 通知；2026-11-14 的生产预览与 2026-11-16 本轮开发服务器各 46 个场景均未捕获该运行异常。未确认早期通知的具体来源，仍需在日常开发环境关注。日志同时发现的 Drawer 废弃 `width` 参数已改为当前 `size` API。
