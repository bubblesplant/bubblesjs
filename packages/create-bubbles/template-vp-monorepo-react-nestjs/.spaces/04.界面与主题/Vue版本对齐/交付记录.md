# Vue 版本对齐交付记录

状态：当前有效。更新日期：2026-11-17。组件库依赖统一已完成；业务、开发代理修复、静态 UI 及路由 Transition 对齐已实施，2026-11-16 的 29 项原生浏览器转场专项全部通过。真实账号及完整业务联调待执行。

## 交付范围

`apps/web-vue` 参照 `apps/web` 实现平台、企业和项目三级管理应用，使用用户指定的 [Antdv Next Pro 官方文档](https://bubblesplant.github.io/antdv-next-pro/)所对应的 `@bubblesjs/antdv-next-pro` 组件库。2026-11-17 已将依赖及锁文件统一为精确版本 `0.3.5`，构建、类型及 50 项单测通过，完整检查限制与浏览器未重验范围见[测试报告](./测试报告.md#2026-11-17-组件库依赖统一)。

- 认证与导航：登录、注册、退出、本人改密、安全跳转、工作空间、权限守卫与服务端撤权反馈。
- 业务页面：25 个管理路由，包含企业／项目、账号／成员、角色权限、菜单及清理预览、审计、资料、字典、组织、岗位和组织模板。
- 组件示例：ProTable、草稿表单、国际化与候选选择器，共 4 个路由。
- 通用能力：ProTable 列表与筛选、SchemaForm 业务弹窗、候选远程搜索与分页、关系有效性校验、字典缓存、加载与失败反馈、中英文、梦幻主题及窄屏导航。
- 请求及状态：Alova Vue、Pinia、会话失效处理、空间切换取消与迟到响应隔离。
- 本轮 UI：统一“万物”品牌、登录与注册、工作空间入口、72px 顶栏、侧栏与手机抽屉、首页及 9 个管理模板；补齐成员显示列、语言键盘交互和桌面导航折叠。
- 路由动画：已接入整页 500ms、同空间内容区 320ms 快照横滑，含快速导航和减少动态效果／不支持 API 降级；19 项单测及 29 项原生浏览器专项通过。

新增共享文件仅扩展[组织与岗位关联校验](../../../packages/shared/src/utils/organization/assignment.ts)及导出，后端继续使用现行契约。主要实现入口为[路由](../../../apps/web-vue/src/router/modules/index.ts)、[布局](../../../apps/web-vue/src/layout/default/index.vue)、[用户状态](../../../apps/web-vue/src/store/modules/user.ts)、[请求控制](../../../apps/web-vue/src/utils/request/workspace.ts)和[业务页面目录](../../../apps/web-vue/src/views/)。

## 启动与复验

在 `apps/web-vue` 目录执行：

```powershell
vp dev
```

沿用项目环境配置；端口与代理配置项为 `VITE_PORT`、`VITE_API_URL`、`VITE_API_AFFIX`。实际后端地址及敏感配置由本地受控环境提供，不写入文档。真实业务使用需要现有 NestJS 及其依赖服务可用。

Vue 默认开发代理与 React 一样连接本地 13000 端口；如服务端端口不同，通过 `.env.development.local` 覆盖 `VITE_API_URL`。修改环境文件后需要开发服务器重新加载配置，页面刷新后重试登录。2026-11-16 已修复旧的 8080 代理目标，当前开发服务器已重新加载，真实登录接口参数校验及未认证请求响应正常，结果见[登录故障回归](./测试报告.md#2026-11-16-登录故障回归)。

本轮独立类型检查、ESLint、90 文件 `vp check --no-fmt`、6 文件 50 项全量单测（含 19 项转场回归）及原有 46 个开发服务器浏览器场景通过；最新生产构建包含 4309 个模块，耗时 2.19 秒。29 项原生浏览器转场专项全部通过，正常 21 项、减少动态效果 4 项、不支持 API 4 项。完整 `vp check` 保留既有 `src/types/auto-import.d.ts` 格式问题记录；本轮没有改该生成文件。无增量类型检查使用 `vp exec vue-tsc --noEmit --incremental false --pretty false`，生产构建使用 `vp build`。详细证据与未覆盖范围见[测试报告](./测试报告.md)。

浏览器工具依赖本机 Playwright 运行时；脚本内标明当前运行时路径，可按本机环境调整。设置 `VUE_TEST_URL` 指向开发服务器或生产预览，`PLAYWRIGHT_EXECUTABLE_PATH` 可指定 Chromium 可执行文件，然后从仓库根目录执行：

```powershell
node '.spaces/04.界面与主题/Vue版本对齐/工具/browser-check.mjs'
```

原生转场专项使用[观察器](./工具/route-transition/observer.mjs)与[执行脚本](./工具/route-transition/run.mjs)，同样通过 `VUE_TEST_URL` 指定 Vue 地址：

```powershell
node '.spaces/04.界面与主题/Vue版本对齐/工具/route-transition/run.mjs'
```

专项输出至[原生转场报告](./测试证据/route-transition-report.json)。当前已修复快照更新等待动画帧造成的超时，`afterEach` 仅等待 Vue `nextTick`；修复后的 29/29 原生浏览器专项通过，结果见[专项记录](./测试报告.md#2026-11-16-路由转场专项)。
