# Vue 版本对齐交付记录

状态：当前有效。日期：2026-11-14。实现及本地验证完成，真实后端联调待执行。

## 交付范围

`apps/web-vue` 参照 `apps/web` 实现平台、企业和项目三级管理应用，使用用户指定的 [Antdv Next Pro 官方文档](https://bubblesplant.github.io/antdv-next-pro/)所对应的 `@bubblesjs/antdv-next-pro` 组件库。

- 认证与导航：登录、注册、退出、本人改密、安全跳转、工作空间、权限守卫与服务端撤权反馈。
- 业务页面：25 个管理路由，包含企业／项目、账号／成员、角色权限、菜单及清理预览、审计、资料、字典、组织、岗位和组织模板。
- 组件示例：ProTable、草稿表单、国际化与候选选择器，共 4 个路由。
- 通用能力：ProTable 列表与筛选、SchemaForm 业务弹窗、候选远程搜索与分页、关系有效性校验、字典缓存、加载与失败反馈、中英文、梦幻主题及窄屏导航。
- 请求及状态：Alova Vue、Pinia、会话失效处理、空间切换取消与迟到响应隔离。

新增共享文件仅扩展[组织与岗位关联校验](../../../packages/shared/src/utils/organization/assignment.ts)及导出，后端继续使用现行契约。主要实现入口为[路由](../../../apps/web-vue/src/router/modules/index.ts)、[布局](../../../apps/web-vue/src/layout/default/index.vue)、[用户状态](../../../apps/web-vue/src/store/modules/user.ts)、[请求控制](../../../apps/web-vue/src/utils/request/workspace.ts)和[业务页面目录](../../../apps/web-vue/src/views/)。

## 启动与复验

在 `apps/web-vue` 目录执行：

```powershell
vp dev
```

沿用项目环境配置；端口与代理配置项为 `VITE_PORT`、`VITE_API_URL`、`VITE_API_AFFIX`。实际后端地址及敏感配置由本地受控环境提供，不写入文档。真实业务使用需要现有 NestJS 及其依赖服务可用。

本地检查使用 `vp check`、`vp test`、`vp exec eslint src test vite.config.ts`、`vp exec vue-tsc -b --pretty false` 与 `vp run build`。结果为 31 项单测及 46 个生产预览浏览器场景通过，详细证据与未覆盖范围见[测试报告](./测试报告.md)。

浏览器工具依赖本机 Playwright 运行时；脚本内标明当前运行时路径，可按本机环境调整。设置 `VUE_TEST_URL` 指向开发服务器或生产预览，`PLAYWRIGHT_EXECUTABLE_PATH` 可指定 Chromium 可执行文件，然后从仓库根目录执行：

```powershell
node '.spaces/04.界面与主题/Vue版本对齐/工具/browser-check.mjs'
```
