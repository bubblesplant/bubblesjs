# Vue 版本对齐

状态：当前有效。更新日期：2026-11-16。业务实现、登录代理修复及本轮 React 界面基准对齐已完成。真实账号及完整业务联调尚未执行，见[测试报告](./测试报告.md)。

## 目标与范围

以 `apps/web` 当前 React 实现为业务基线，在 `apps/web-vue` 实现对应 Vue 应用。采用用户指定的 [Antdv Next Pro](https://bubblesplant.github.io/antdv-next-pro/)（`@bubblesjs/antdv-next-pro`），复用现有 NestJS 接口及 `shared` 类型、权限目录和工具。

- 登录、注册、登录失效、退出及本人修改密码。
- 工作空间选择及平台、企业、项目三级路由、菜单、权限和切换。
- 首页、企业与项目管理、账号、角色、成员、菜单、审计、资料、字典、组织、岗位及组织模板。
- React 已发布的 ProTable、草稿、国际化及选择器示例。
- UI 以 `apps/web` 当前实际界面为视觉基准，统一“万物”品牌、登录／注册页、工作空间选择、顶栏／侧栏、首页及管理表格的结构、色彩、字体、间距与响应式表现；保留中文／英文切换、加载／空态／失败重试。

## 业务与权限

权限以服务端 `/access` 为准，不从本地展示缓存恢复授权。空间切换、账号变化时旧请求不得回写新空间。直达受保护路由同样校验权限。企业和项目的对象标识来自当前路由；接口查询及修改遵守现有版本条件。账号、密码、令牌不进入项目文档或截图。

## 验收标准

1. React 已发布路由在 Vue 中均有对应可用页面，管理操作调用同一后端接口。
2. 列表使用指定 ProTable；表单、弹窗、筛选、分页、权限及失败反馈可用。
3. 登录与空间导航可完成，权限不足和会话失效有明确去向。
4. Vue 类型、构建、代码检查及关键行为测试通过；浏览器验证范围与依赖外部服务的限制如实归档。
5. 本地开发时 Vue 与 React 使用同一 NestJS 后端；Vue 默认开发代理与服务端默认端口保持一致，登录请求不得因指向未启动的后端地址而返回 502。
6. 桌面 1440px 与移动 390px 对照 React 验证登录、注册、空间选择、企业首页及成员管理；品牌、背景、玻璃面板、导航层级及表格样式一致，窄屏无整页横向溢出，菜单与表单仍可操作。组件库造成的细节差异不得改变页面结构和主要视觉层级。

## 实施与验收

已实现平台 7、企业 10、项目 8 个管理路由，以及 4 个组件示例。认证、空间、权限、字典、组织和岗位等功能按现行共享 DTO 与 React 接口适配。2026-11-16 重新通过 Vue 类型检查、生产构建及 31 项单元测试，并完成本轮浏览器行为与桌面／移动端视觉回归，证据见[测试报告](./测试报告.md)。浏览器使用虚构 API 数据，不代表真实 NestJS、数据库或外部服务联调通过。入口、截图与运行说明见[交付记录](./交付记录.md)。
