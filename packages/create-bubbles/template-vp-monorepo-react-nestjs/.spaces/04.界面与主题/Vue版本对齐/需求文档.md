# Vue 版本对齐

状态：当前有效。日期：2026-11-14。Vue 实现与本地验证已完成；真实后端联调尚未执行，见[测试报告](./测试报告.md)。

## 目标与范围

以 `apps/web` 当前 React 实现为业务基线，在 `apps/web-vue` 实现对应 Vue 应用。采用用户指定的 [Antdv Next Pro](https://bubblesplant.github.io/antdv-next-pro/)（`@bubblesjs/antdv-next-pro`），复用现有 NestJS 接口及 `shared` 类型、权限目录和工具。

- 登录、注册、登录失效、退出及本人修改密码。
- 工作空间选择及平台、企业、项目三级路由、菜单、权限和切换。
- 首页、企业与项目管理、账号、角色、成员、菜单、审计、资料、字典、组织、岗位及组织模板。
- React 已发布的 ProTable、草稿、国际化及选择器示例。
- 延续现有梦幻主题、中文／英文切换、响应式布局、加载／空态／失败重试。

## 业务与权限

权限以服务端 `/access` 为准，不从本地展示缓存恢复授权。空间切换、账号变化时旧请求不得回写新空间。直达受保护路由同样校验权限。企业和项目的对象标识来自当前路由；接口查询及修改遵守现有版本条件。账号、密码、令牌不进入项目文档或截图。

## 验收标准

1. React 已发布路由在 Vue 中均有对应可用页面，管理操作调用同一后端接口。
2. 列表使用指定 ProTable；表单、弹窗、筛选、分页、权限及失败反馈可用。
3. 登录与空间导航可完成，权限不足和会话失效有明确去向。
4. Vue 类型、构建、代码检查及关键行为测试通过；浏览器验证范围与依赖外部服务的限制如实归档。

## 实施与验收

已实现平台 7、企业 10、项目 8 个管理路由，以及 4 个组件示例。认证、空间、权限、字典、组织和岗位等功能按现行共享 DTO 与 React 接口适配。31 项单元测试及生产预览的 46 个浏览器场景通过，类型、代码检查及生产构建通过。浏览器通过虚构 API 数据验证页面、请求与交互，不代表真实 NestJS、数据库或外部服务联调通过。入口、截图与运行说明见[交付记录](./交付记录.md)。
