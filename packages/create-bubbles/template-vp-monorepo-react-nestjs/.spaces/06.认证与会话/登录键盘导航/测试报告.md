## 实现与交付

账号字段使用 `allowClear: { tabIndex: -1 }`，密码字段使用 `visibilityToggle: { tabIndex: -1 }`。两个辅助按钮保留鼠标操作；Tab 顺序为账号 → 密码 → 登录按钮，Shift+Tab 按相反顺序返回。
