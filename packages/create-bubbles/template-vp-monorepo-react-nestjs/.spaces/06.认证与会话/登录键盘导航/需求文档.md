# 登录键盘导航

- 状态：当前有效；账号清空按钮与密码显示按钮均已实现并完成浏览器专项验证。
- 日期：2026-11-12。
- 范围：Web 登录页账号清空按钮与密码显示／隐藏按钮。

## 需求与验收

账号输入后按 Tab，应直接进入密码框；Shift+Tab 应从密码框返回账号框，避免在账号右侧的清空按钮多停一次。清空按钮继续支持鼠标点击，清空后焦点保留在账号框；键盘用户可用全选后删除清空内容。

密码显示／隐藏的小眼睛也应跳过 Tab，保留鼠标点击切换。登录表单内的正向 Tab 顺序为账号 → 密码 → 登录按钮，Shift+Tab 按相反顺序返回；密码为空或有值时均一致。登录按钮、语言入口和注册入口继续保留各自的键盘操作。本次不调整认证接口、权限、数据约束、会话和账号校验规则。

## 交互与实现设计

ProFormText 默认启用清空按钮，底层输入框将其渲染为可聚焦的原生 button。账号框使用公开配置 `fieldProps.allowClear: { tabIndex: -1 }`，密码框使用 `fieldProps.visibilityToggle: { tabIndex: -1 }`，将两个辅助按钮移出 Tab 顺序。不拦截页面键盘事件、不修改组件库和 DOM。

验收覆盖账号及密码空值／有值时的正向 Tab、登录到密码及密码到账号的反向 Shift+Tab、鼠标清空及清空后焦点、键盘全选删除、鼠标切换密码显示与隐藏。执行结果见[测试报告](./测试报告.md)。
