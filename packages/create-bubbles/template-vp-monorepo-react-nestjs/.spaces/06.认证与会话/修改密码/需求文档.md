# 修改密码需求文档

## 1. 文档状态

- 状态：待实施；以下规则已确认，当前前后端尚无本人改密或管理员重置密码功能。
- 整理日期：2026-09-30。
- 当前认证与会话基线见 [会话管理需求文档](../会话管理/需求文档.md) 和 [会话管理技术契约](../会话管理/技术契约.md)。本文描述待实施的业务需求，不把拟新增能力写成现行接口。

## 2. 背景与目标

当前用户注册后无法自行修改密码，管理员也无法为忘记密码的用户重置密码。账号是跨工作空间使用的全局身份；密码变更必须作用于全局账号，并及时使旧登录状态失效。

本功能让已登录用户验证旧密码后修改自己的密码，让平台管理员为其他全局账号设定新密码，同时保护密码内容与各终端会话。

## 3. 范围与入口

- 本人改密属于账号级功能，不依赖企业、项目成员身份或工作空间权限；已登录但没有任何工作空间的用户也必须能从工作空间选择页进入。进入工作空间的用户可从全局账号入口进入。
- 管理员重置入口位于平台账号管理，仅平台管理员可操作；企业管理员和项目管理员不能重置全局账号密码。平台管理员不能通过此入口重置自己的密码，应使用本人改密流程。
- 管理员可重置其他已存在的全局账号。重置不改变账号的启用、锁定或停用状态，也不改变角色、成员关系；不能登录的账号不会因重置密码而自动恢复登录资格。
- 本期不包含未登录用户的忘记密码找回、邮件或短信发送、自动生成临时密码，也不要求管理员重置后的首次登录强制改密。

## 4. 业务流程与规则

### 4.1 本人修改密码

1. 已登录用户输入旧密码、新密码和确认密码；密码输入不预填，确认密码必须与新密码一致。
2. 服务端验证当前会话、旧密码以及新密码。新密码沿用当前注册校验的 8–16 位长度规则，且不得与旧密码相同；仅前端校验不能代替服务端校验。
3. 验证通过后更新该全局账号的密码摘要，并撤销该用户在 Web、桌面端和移动端的全部会话，包括发起改密的当前会话。前端清除本地登录凭据并跳转登录页；用户须使用新密码重新登录。
4. 旧密码错误、输入不合法或处理失败时，不更新密码，也不提示修改成功；允许用户修正输入后重试。

### 4.2 平台管理员重置他人密码

1. 平台管理员在平台账号管理中选择其他全局账号，输入新密码和确认密码；无须提供目标账号的旧密码。
2. 新密码同样遵循 8–16 位长度规则，确认密码必须一致。成功后更新目标账号的密码摘要，撤销目标账号全部终端会话；管理员自己的会话保持有效。
3. 管理员通过现有线下渠道把自己设定的新密码交给用户。系统不发送密码，也不在成功响应或操作记录中回显密码。用户下次使用新密码登录后可直接使用原有权限，不强制再次改密。
4. 目标账号不存在、操作者无权或处理失败时，不更新密码，也不提示重置成功。

## 5. 权限、安全与数据约束

- 本人改密只允许作用于当前会话对应的 `userId`；管理员重置须同时满足有效登录和平台管理员身份，并由服务端校验操作者与目标不是同一账号。页面隐藏操作入口不能代替服务端鉴权。
- 明文密码仅用于本次校验与生成密码摘要；数据库只保存摘要。明文密码及摘要不得写入接口响应、日志、审计摘要、测试证据或截图。密码摘要算法沿用当前认证实现。
- 为本人改密和管理员重置记录可追溯的安全操作结果，包括操作人、目标账号、操作类型、时间与成功或失败结果；目标未解析时不伪造目标身份。失败记录的载体和字段在实施契约中确定，不改变现行管理审计只记录成功变更的既有口径。
- 密码更新和目标全部终端会话撤销共同构成成功条件。会话撤销失败时不得返回成功，密码应保持原值；实现方案须处理数据库与会话存储之间的一致性，并避免暴露底层错误或凭据。

## 6. 验收标准

1. 已登录用户在没有工作空间时仍可进入本人改密；旧密码正确、两次新密码一致且符合规则时可改密，随后当前及其他终端旧会话均失效，旧密码不能再登录，新密码可以登录。
2. 旧密码错误、新旧密码相同、新密码长度不符或确认密码不一致时，密码保持原值，不显示成功结果。
3. 平台管理员可重置其他已有账号；目标账号全部旧会话失效，管理员会话不受影响，目标账号状态、角色和成员关系保持原样，首次使用新密码登录不被强制再次改密。
4. 平台管理员不能从重置入口重置自己；企业或项目管理员、未登录用户不能重置全局账号密码。目标不存在或会话撤销失败时，密码保持原值，不显示成功结果。
5. 响应、日志、审计和归档证据均不含明文密码或密码摘要；安全操作记录能够区分操作人、目标账号和结果。

## 7. 实施前待确认事项

- 接口路径、共享请求与返回类型、错误码及权限标识须在实施前写入技术契约；本文不定义尚未实现的端点。
- 失败操作记录的载体和保留规则，以及密码更新与会话撤销的一致性方案，须在设计和技术契约中明确。
