| --- | --- | --- |

## 3. 联调发现与待确认

- 安全审查发现管理员重置请求的未知字段名可能进入 400 响应，以及重置时认证存储／审计故障可能返回与契约不符的 500。Server 已针对这两项修改，并在定向自动化中复测；隔离存储专项已验证一次性注入撤销故障的数据库回滚，运行态 Redis 停机故障尚未执行。
- 隔离 PostgreSQL／Redis 5 项专项验证了本人改密和管理员重置成功路径、三终端旧会话撤销、管理员会话保留、一次性注入的撤销故障回滚与自重置拒绝。此专项直接调用服务，不代表已经通过浏览器到后端的运行态全链路。
- Web 全量测试受既有 Node `localStorage` 加载条件和 happy-dom 本地 HTTP CORS 限制影响；具体运行数字和边界见[测试报告](./测试报告.md)。
- 当前尚无真实浏览器端到端证据；部署日志的实际保留期限和检索能力也尚未核验。
