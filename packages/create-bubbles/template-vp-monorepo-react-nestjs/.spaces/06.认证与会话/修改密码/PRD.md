# 修改密码 PRD

## 1. 状态与依据

- 状态：当前有效交互依据；页面与交互已在当前工作树实现，自动化验证范围及浏览器端到端待补项见[测试报告](./测试报告.md)。
- 需求来源：[修改密码需求文档](./需求文档.md)。现行会话规则见[会话管理需求文档](../会话管理/需求文档.md)。
- 本文只描述用户可见流程；服务端权限、接口、错误和一致性以[技术契约](./技术契约.md)为准。

## 2. 用户故事与入口

| 用户 | 诉求 | 入口 |
| --- | --- | --- |
| 已登录的全局账号用户 | 验证旧密码后自行修改密码 | 工作空间选择页的账号操作；进入任一工作空间后的全局账号操作 |
| 没有工作空间的已登录用户 | 仍能自行改密 | `/workspaces` 工作空间选择页的账号操作，不依赖工作空间权限 |
| 平台管理员 | 为其他全局账号直接设定新密码 | `/platform/accounts` 目标账号的行操作；本人行不提供重置入口 |

企业或项目管理员不会因其作用域身份获得平台重置入口。页面条件只是辅助；服务端仍须按[技术契约](./技术契约.md)鉴权。

## 3. 页面与交互流程

### 3.1 本人修改密码

1. 用户从账号操作打开修改密码表单。表单提供旧密码、新密码、确认密码；三个输入框均不预填，也不在返回页面时保留输入。
2. 前端检查三项必填、两次新密码一致、新密码为 8–16 位以及新旧密码不同。提交期间阻止重复提交；服务端再次执行完整校验。
3. 成功时清理本地登录凭据和进行中的工作空间请求，跳转 `/login`；提示用户使用新密码重新登录。发起改密的当前会话和其他终端旧会话均应失效。
4. 失败时停留在表单，显示可公开的字段或业务错误并允许修正重试；不得显示成功提示，不清理仍有效的本地会话。密码字段不写入 URL、持久存储或客户端日志。

### 3.2 平台管理员重置

1. 平台管理员在全局账号列表选择非本人账号，打开重置密码表单。显示目标账号的公开标识供核对，输入新密码与确认密码，不要求旧密码。
2. 前端检查两次输入一致、新密码为 8–16 位；提交期间阻止重复提交。服务端独立校验平台管理员身份、目标存在且不是操作者本人。
3. 成功时关闭表单并提示通过现有线下渠道告知用户；不展示、不复制、不发送或回显新密码。管理员当前登录保持有效，目标账号原有各终端会话失效。
4. 失败时保留可修正的界面并显示公开错误，不提示成功。目标账号状态、角色与成员关系均不因重置变化。

## 4. 验收映射

| 场景 | 预期结果 | 需求对应 |
| --- | --- | --- |
| 无工作空间的已登录用户改密 | 可进入表单；成功后回登录页，旧密码与旧会话失效，新密码可登录 | 6.1 |
| 旧密码错误、两次输入不一致、长度非法或新旧相同 | 无密码变更和成功提示；可修正重试 | 6.2 |
| 平台管理员重置其他账号 | 目标全部旧会话失效；操作者会话有效；目标状态及关系不变；下次登录不强制再改密 | 6.3 |
| 平台管理员重置自己、非平台管理员操作、目标不存在或撤销失败 | 服务端拒绝或报告失败，密码保持原值，不显示成功 | 6.4 |
| 凭据和操作记录 | 响应、日志、审计、截图无密码明文或摘要；操作结果可追溯 | 6.5 |

表中“需求对应”指[修改密码需求文档](./需求文档.md)第 6 节；实际执行证据应归档到本功能的测试报告，不以本文代替测试结果。

## 5. 范围外事项

未登录忘记密码找回、自动发送密码、自动生成临时密码和首次登录强制改密均不在本期范围；详见[需求文档](./需求文档.md)。
