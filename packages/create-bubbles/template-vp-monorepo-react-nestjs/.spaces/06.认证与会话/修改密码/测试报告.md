## 3. 验收场景与未覆盖项

| 场景 | 当前证据 | 待补验证 |
| --- | --- | --- |
| 无工作空间用户进入本人改密、成功后回登录页 | Web 页面与会话清理定向自动化；真实存储验证旧密码登录失败、新密码登录成功 | 真实浏览器和后端全过程联动 |
| 旧密码错误、密码复用、输入不合法时无密码变更 | Server 定向自动化覆盖旧密码错误、复用与未知字段清洗；真实存储专项验证撤销故障时摘要原值 | 长度、确认密码及其他输入失败逐项进行真实 HTTP 与数据库核对 |
| 平台管理员重置他人、自重置拒绝、越权拒绝、目标不存在 | Server 定向自动化；真实存储专项验证重置他人和自重置拒绝 | 非平台管理员、目标不存在的真实权限数据与 HTTP 联动；锁定／停用账号状态保持 |
| 撤销目标 Web、桌面端、移动端会话，管理员自身会话保持 | 真实 Redis 三终端 Lua 校验：本人和重置目标旧会话失效，管理员 Web 会话有效 | 真实浏览器与其他端客户端交互 |
| Redis 撤销失败时密码和成功审计回滚，旧密码并发登录不能重新建会话 | 真实 PostgreSQL 验证一次性注入的撤销故障会回滚摘要及成功审计，原会话有效；Server 定向自动化验证登录摘要复核 | 真实并发时序与运行态 Redis 停机故障 |
| 响应、安全事件、管理审计和普通日志无密码明文或摘要 | Server 定向自动化覆盖固定安全事件与错误日志，代码审查已发现并修复两处问题 | 运行态日志、响应与审计数据抽检；部署日志保留期限与检索能力确认 |

浏览器端到端场景、运行态安全事件／普通日志抽检，以及部署日志保留和检索能力尚待记录；不能据当前自动化与服务层集成结果认定[需求文档](./需求文档.md)第 6 节全部通过。相关前后端核对见[联调记录](./联调记录.md)。
