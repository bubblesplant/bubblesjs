## 本次交付范围

在此前 Vite+ library 基础上实现 [agent 包](../../../packages/agent/package.json)。[公开入口](../../../packages/agent/src/index.ts) 导出 `bootstrapAgent()`、`createAgentHost()`、模型适配器、`defineTool()` 和运行类型。

- 包名：`agent`，版本 `0.0.0`，private，Node.js `>=22`。
- 输出：`dist/index.mjs`、`dist/index.d.mts`、`dist/process/worker.mjs` 及共享构建块；ESM，构建目标 ES2023。
- 主代理、同进程定义／工厂／借入实例、独立进程均经 `bootstrapAgent()` 初始化，执行同一套模型与工具循环。
- 原生 fetch 适配 Anthropic Messages 和 OpenAI Chat Completions；允许可恢复故障切换备用模型，已完成工具不重放。
- Zod 定义并校验工具参数；宿主与祖先授权共同约束执行。内置 `delegate_agent` 只能调用已声明的子代理。
- 实例、session、run 分层；会话内串行，会话间并发，成功后提交历史，异步身份互相隔离。
- 预算、深度、取消与模型并发覆盖整棵代理树，跨进程也由父级协调；模型名额在执行工具和等待子代理时释放。
- 进程由可信模块工厂重建模型和工具，worker 可复用；取消、异常退出及关闭资源均有确定结果，自有资源与借入实例分别管理。
- 包的格式、lint 和类型配置复用 workspace，依赖版本沿用 catalog；运行依赖为 Zod，未引入完整第三方 Agent 框架。

本轮没有实现 MCP、Skills、token delta、提问／审批恢复、持久化、后台 DAG、结构化最终结果、多模态、NestJS 及浏览器／PC 执行器。进程代理提供执行隔离，不构成操作系统安全沙箱。

## 使用命令

在模板根目录安装依赖：

```sh
vp install
```

在 `packages/agent/` 中运行：

| 命令               | 用途                         |
| ------------------ | ---------------------------- |
| `vp run dev`       | 监听源码并生成库产物         |
| `vp run build`     | 构建 ESM 与类型声明          |
| `vp run check`     | 格式、lint 及类型检查        |
| `vp run typecheck` | 单独运行 TypeScript 类型检查 |
| `vp run test`      | 构建产物后执行 22 项专项测试 |

也可在模板根目录通过 `vp run --filter agent <任务名>` 调用对应包任务。
