# 智能体运行时技术契约

状态：当前有效；本轮核心实施依据。日期：2026-11-14。

## 入口与配置

- `createAgentHost({ maxConcurrentModels?, onEvent?, authorize? })`：管理模型并发和实例资源。
- `bootstrapAgent({ definition, host? })`：统一初始化本地 AgentDefinition 或 `kind: 'process'` 描述。未传 host 时创建私有宿主。
- `instance.run({ input, sessionId?, signal?, limits? })`：返回 RunResult；`instance.close()` 可重复调用。
- `instance.history(sessionId)` 返回拷贝；`clearSession(sessionId)` 只允许空闲会话。
- `defineTool({ name, description, schema, execute, timeoutMs? })`：Zod 同时提供模型 JSON Schema 与真实参数校验。
- `createAnthropicModel()`、`createOpenAIModel()`：配置 baseUrl、model、apiKey、可选认证方式和 fetch。
- `currentAgentContext()`：当前异步链的只读 agentId、agentName、runId、sessionId、parentRunId、depth。

AgentDefinition 包含 name、systemPrompt、model、fallbacks、tools、subagents、limits、authorize、dispose。subagents 的值可以是定义、异步工厂、已有实例或进程描述。内置 `delegate_agent` 工具只接受已声明名称；业务工具可用 `context.delegate({ agent, input })` 与 Promise.all 显式并行汇合。

ProcessAgentSpec 包含 kind、name、module（绝对路径或 file URL）、exportName（默认 default）、config（JSON）。可信模块导出 `(config) => AgentDefinition | Promise<AgentDefinition>`，每个 worker 启动时调用一次。工厂在子进程读取环境凭证并重新初始化模型和工具，不将密钥放入 config。

## 状态与预算

RunResult 状态为 completed、failed、cancelled、limit_exceeded，包含 identity、output、usage 和可选 error `{ code, message }`。usage 为该运行完成时整树已报告用量快照；根结果涵盖子树。未知异常转换为通用错误，不泄露底层请求正文。

| 配置                | 默认值 | 约束                                |
| ------------------- | ------ | ----------------------------------- |
| timeoutMs           | 120000 | 含 session 排队，后代只能收紧       |
| maxSteps            | 12     | 每次运行模型回合数                  |
| maxModelCalls       | 24     | 整树请求数，含备用请求              |
| maxToolCalls        | 32     | 整树工具数，含内置委派              |
| maxSubagents        | 8      | 整树委派数                          |
| maxDepth            | 4      | 根深度 0                            |
| maxTokens           | 100000 | 已报告 input + output，响应后核算   |
| maxOutputTokens     | 2048   | 与剩余报告预算取小值                |
| maxConcurrentModels | 4      | host 级模型并发，工具和等待不占名额 |

限额必须是正安全整数。子限制与祖先取小值。token 限额依据服务端报告，不承诺精确限制计费。工具默认超时 30 秒；不配合 signal 的外部工具可能已产生副作用，取消无法撤销。

仅网络故障、408、429、5xx 可以切换备用模型；重发当前请求，不重放成功工具。认证错误、无效响应不 fallback。参数错误、权限拒绝与工具失败以安全 tool result 回给模型；预算与取消直接终止。

事件包括 run.started／completed／failed／cancelled、model.started／completed／fallback、tool.started／completed／failed、agent.delegated，含身份和时间。事件不自动携带提示词、工具参数／结果或底层异常；回调异常不影响运行。首期无 token delta 或审批恢复。

## 使用

```ts
import { bootstrapAgent, createAnthropicModel, defineTool } from 'agent'
import { z } from 'zod'

const model = createAnthropicModel({
  baseUrl: process.env.AGENT_BASE_URL!,
  model: process.env.AGENT_MODEL!,
  apiKey: process.env.AGENT_API_KEY!,
})
const agent = await bootstrapAgent({
  definition: {
    name: 'assistant',
    systemPrompt: '需要时委派计算。',
    model,
    subagents: {
      calculator: {
        name: 'calculator',
        systemPrompt: '使用 add 计算。',
        model,
        tools: [
          defineTool({
            name: 'add',
            description: '相加两个数字',
            schema: z.object({ a: z.number(), b: z.number() }),
            execute: ({ a, b }) => ({ sum: a + b }),
          }),
        ],
      },
    },
  },
})
try {
  const result = await agent.run({ input: '让 calculator 计算 17 + 25' })
  console.log(result.status, result.output)
} finally {
  await agent.close()
}
```

Anthropic baseUrl 可为完整 /messages 地址或网关前缀，后者追加 /v1/messages；以 /v1 结尾时只追加 /messages。默认 x-api-key，可选 bearer。OpenAI 同理追加 /v1/chat/completions。首期支持非流式文本与 function calling，不输出内部推理。
