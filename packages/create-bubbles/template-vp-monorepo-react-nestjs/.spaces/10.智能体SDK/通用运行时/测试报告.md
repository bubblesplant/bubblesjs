- 本轮只执行 agent 包专项，没有运行整个 monorepo 的全量检查或其他应用测试。
- OpenAI 使用本机 HTTP 协议测试，未验证真实 OpenAI 服务；真实外部模型仅为上述 DeepSeek 网关。
