# 前端请求层适配技术契约

- 状态：2026-10-23 兼容迁移、登录成功重置与统一本地会话清理已实现并通过专项验证。
- 业务协议引用[API 与统一错误技术契约](../技术契约.md)；空间隔离引用[权限与菜单技术契约](../../01.企业级项目级/权限与菜单/技术契约.md)。

## 实例与响应

- 通用请求使用命名导出的 `alovaRequest` 原生实例，配置遵循 `baseURL`、`beforeRequest`、`responded` 和方法级 `meta`。
- 工厂的开发环境判断采用 Vite 浏览器环境变量 `import.meta.env.DEV`，避免 Web 类型检查依赖 Node 的 `process` 全局；保持仅开发环境开启缓存日志的意图。
- 401 导航时才动态加载路由，打断请求工具 → 路由 → 页面／空间请求 → 通用请求的静态循环；直接加载请求模块时不得提前读取未初始化的实例。
- 默认结果为 `AxiosResponse.data`；`meta.isTransformResponse: true` 保留完整响应，泛型由调用方明确指定。失败继续抛出原始 Axios 异常，不将服务端业务码覆盖到 `AxiosError.code`。
- 工作空间实例通过原生工厂复用通用实例配置和成功响应处理；错误拦截器仅向外抛出，待 `runSessionRequest`／`runWorkspaceRequest` 校验有效性后处理已有 401／403 行为，防止全局副作用提前执行。
- 登录、注册通过原生工厂建立公开实例，仅复用接口前缀和成功正文语义，不绑定鉴权头或全局错误导航；其错误继续由原表单展示。
- 改密、退出直接使用通用实例，单次请求使用 `meta.isShowErrorMessage: false`，保留原有本地错误反馈。涉及密码的请求关闭缓存和请求共享。

## 空间生命周期与错误展示

- 保留 `currentKey`、`generation`、在途中止集合及 `AbortSignal`；身份键仍由令牌与创建 API 时绑定的工作空间键组成。
- 过期请求统一拒绝为 `AbortError`，不得处理迟到的 401／403。
- 当前空间／会话 401 在过期校验后调用 `unAuthorizedResponseFunc`，与普通实例共用清理、去重提示及 SPA 导航，空间调用方不再重复清 token。
- 当前业务 403 刷新权限；权限上下文请求本身不递归刷新。
- 页面读取公开失败文案时优先采用 `response.data.message`，普通 `Error` 继续使用其消息，缺失时使用页面原有兜底。公共消息读取方法归入 `packages/shared/src/utils`，不依赖 Axios，不修改原异常。
- 登录成功写入 token 后、导航前调用 `resetUnauthorizedHandled`；失败不重置。
- 统一失效入口同步删除 token 及工作空间／字典专属快照。删除 token 即使前后均不存在也触发 `auth-session-change`，用户与字典监听在无 token 时强制清内存与在途操作；空间监听同步推进代次并中止请求，监听须支持 HMR 卸载。通过同步事件复用现有 store 清理，不静态导入 store／空间请求而重新引入循环依赖。
- 快照删除复用独立持久化模块，保证 store 尚未加载时也清除旧快照；不得全量清空 localStorage／sessionStorage。
- 普通请求主动取消提示策略及普通实例的迟到 401 换号保护继续待确认。
