## 检查边界与遗留

- 根目录 `vp check` 首次运行因 252 个文件的格式问题退出，其中包括当时尚未格式化的本轮修复前 JSON；本轮产物已单独格式化并检查，不批量修改其他既有文件，全仓检查不能标记通过。
- 构建仍输出既有 `MODULE_TYPELESS_PACKAGE_JSON` 警告，涉及 `rspack.config.ts` 的模块类型识别；与本次 pg 查询警告不同，构建成功。
- 未连接真实 PostgreSQL、Redis 或对象存储，43 项外部集成测试跳过；未执行数据库迁移，也未操作业务库。本次没有建立需要安装依赖的临时测试项目。
- 原始警告未附调用栈，因此没有确认用户当时访问的具体页面，也不能据此宣称实际运行环境中的所有 pg 警告均已消失。
- 当前生产源码剩余的 `Promise.all`／`Promise.race` 位于上传内容摘要模块，管理独立 Worker 与流，不共用数据库事务查询连接。
