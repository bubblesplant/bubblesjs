# 工具函数迁移

状态：当前有效；实现及专项验证完成，范围见[测试报告](./测试报告.md)。

## 目标与范围

根据 2026-10-16 的依赖统一要求，本模板使用 `es-toolkit` 替换现有工具函数依赖，版本范围为 `^1.52.0`。范围包括工作区 catalog、Vue 应用依赖、图表尺寸防抖调用及锁文件；业务接口、权限和数据模型保持现有规则。

## 实施约束

- 图表尺寸变化继续采用 100ms 的尾沿防抖，使用 `debounce(resize, 100)`。
- 组件卸载时断开尺寸观察器，并通过防抖函数的 `cancel()` 取消待执行回调，再释放图表，避免延迟回调访问已释放实例。
- 锁文件仅替换本次依赖，不主动升级其他依赖；历史发布记录保留原始事实。

## 验收标准

- 模板现行源码、依赖声明和锁文件不再引用旧工具函数依赖。
- Vue 应用类型检查、构建及生成模板冒烟验证通过；无法执行的检查在测试报告中明确记录。
- 连续尺寸变化合并执行，取消后不执行待处理回调。
