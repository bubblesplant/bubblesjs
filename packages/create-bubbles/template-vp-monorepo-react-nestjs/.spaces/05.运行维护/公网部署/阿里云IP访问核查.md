# 阿里云大陆服务器未备案 IP 访问核查

状态：官方公开文档核查记录；核查日期为 2026-10-27。未购买服务器、未实际测试公网访问、未联系阿里云客服，不代表针对具体账号或个人封闭测试场景的工单答复。

## 本次问题

用户仅作个人访问和演示，希望使用阿里云中国大陆服务器，通过公网 IP 访问网页，不买域名、不备案、不使用内网穿透，每月不超过 50 元；香港地域已排除。当前需要判断阿里云是否明确允许这一访问组合，需求以[需求文档](./需求文档.md)为准。

## 当前结论

- 阿里云针对 IP 网站的专项说明明确要求：中国大陆服务器上，没有绑定域名、直接通过 IP 对外提供网站服务，也需要 ICP 备案。因此不能把“没有域名”作为公网 Web 服务免备案的依据。
- 官方公开文档中未查到“仅个人访问和演示”即可免备案公开网站的明确豁免。仅本人封闭测试是否有例外，仍需阿里云针对实际访问范围与用途答复，不能自行认定。
- 阿里云代备案系统只支持域名备案，不支持 IP 备案；官方限制说明将 IP 网站备案申请指向当地通信管理局系统。这不构成当地一定受理或批准的保证。
- 另一篇官方 FAQ 对“只购买服务器不使用域名”给出了不需要备案的概括答复，与专项 IP 网站说明存在表述差异。对本项目的网页访问，应优先参考直接针对 IP 网站的条款；不能用概括 FAQ 承诺未备案 IP 网站被官方允许或可持续访问。
- ECS 活动的资源价格不证明访问方式符合接入要求。当前不能认定阿里云大陆公网 IP 网页演示已满足用户的“暂不备案”约束，也不应仅凭低价完成采购。

## 官方证据

### 直接针对 IP 网站的说明

来源：[阿里云《通用网站进行 ICP 备案》](https://help.aliyun.com/zh/icp-filing/basic-icp-service/product-overview/icp-filing-requirements-for-a-regular-website)，定位“通过 IP 访问的网站进行 ICP 备案”。

> 托管于中国内地服务器上的网站，如果网站没有绑定域名，直接通过 IP 地址对外提供服务也需要进行 ICP 备案。目前阿里云 ICP 代备案管理系统只支持域名备案，不支持 IP 备案。

同页进一步说明，无论通过 IP 还是域名对外提供服务，未备案成功前均不允许开通网站访问。

### IP 备案办理入口的限制

来源：[阿里云《限制说明》](https://help.aliyun.com/zh/icp-filing/basic-icp-service/product-overview/limits)，定位“只通过 IP 访问的网站或 App 进行 ICP 备案”。

> 阿里云 ICP 代备案管理系统不支持 IP 备案仅支持域名备案。如果您的网站或 App 只能通过 IP 访问，请在当地通信管理局网站的备案系统中申请备案。

### 概括 FAQ 的不同表述

来源：[阿里云《不同场景下的 ICP 备案说明 FAQ》](https://help.aliyun.com/zh/icp-filing/basic-icp-service/product-overview/faq-about-icp-filing-applications-in-different-scenarios)，定位“只购买云服务器不使用域名，需要进行 ICP 备案吗？”。

> 不需要。当域名解析指向中国内地服务器且开通 Web 服务时才需进行 ICP 备案。

该问答没有明确解释“通过公网 IP 对外提供网站”与上述专项条款的关系，因此不能单独作为本项目公网 Web 演示免备案的肯定依据。

### 未备案 Web 服务的一般说明

来源：[阿里云《备案场景及基本概念 FAQ》](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/faq-about-icp-filing-preparations)，定位“首次备案对网站访问的影响？”。

该文说明未备案成功的网站不能对外开通 Web 服务。文中支持个人性质备案，但没有将个人演示列为免备案的例外。

## 尚未证实的事项

- 只有用户本人、以限制访问来源等方式进行的封闭测试，是否在阿里云具体产品和地域有明确适用规则；不能把访问控制措施当作自动免备案依据。
- 某个具体实例或端口在未备案状态下是否可以连接、是否会被拦截。本次不开展任何验证或规避接入限制的操作；技术上能够访问也不能替代官方许可。
- 东京、新加坡等其他阿里云地域的可购套餐、价格及用户实际网络访问表现；本次没有改变用户选择或将 99 元年费活动套用于海外地域。
