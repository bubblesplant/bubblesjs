# 公网部署

状态：个人演示、中国大陆访问、每月不超过 50 元、不买域名、不备案且排除香港的约束已确认；阿里云官方专项文档明确大陆 IP 网站对外提供 Web 服务也需备案，不能认定当前大陆方案满足免备案要求。个人封闭测试是否有例外、具体首购价格及后续选型仍待确认，尚未部署。核查依据见[阿里云 IP 访问核查](./阿里云IP访问核查.md)。

## 目标与范围

- 将当前项目部署到有公网入口的托管环境，供用户本人访问和个人演示；当前不按正式对外业务或高并发场景选型。
- 用户明确排除内网穿透方案，希望成本经济、访问速度较好。
- 主要访问者位于中国大陆；每月预算不超过 50 元人民币，暂不考虑需要办理大陆 ICP 备案的部署路线。
- 用户明确排除香港地域，并希望评估阿里云。已核实其专项文档要求大陆 IP 网站对外提供 Web 服务也需备案；仅个人封闭测试是否有例外仍未获得明确答复，不能将未备案公网 IP 网页演示当作已获允许的方案。
- 不购买域名，直接通过服务器公网 IP 访问；服务器需提供适合目标访问者直接连接的公网 IPv4。
- 按整体成本评估服务器、公网 IP、备份及超额流量，年付费用需折算月均，并单独说明首次付款金额和续费成本；不再预留域名购买费用。
- 当前范围为核对运行依赖和比较部署方案；尚未选择供应商、购买资源或执行线上变更。
- 本次补充核验 Cloudflare 是否适合当前完整项目，分别评估前端、NestJS、数据库、Redis／BullMQ 和对象存储，并按官方现行价格给出条件明确的费用测算；本次不购买资源或发布应用。
- 补充比较 Vercel：核对 React 静态前端、NestJS／Fastify Functions、后台消费者及上传限制，区分个人演示免费条件和收费套餐；复用已完成的本地构建证据，不将其当作 Vercel 云端部署验证。
- 公网部署沿用现有业务权限与数据约束，不因开放公网入口放宽认证、企业或项目访问边界。

## 当前项目依据

- [React 前端配置](../../../apps/web/package.json)：Vite 构建，可由 Web 服务器提供静态文件；当前构建脚本显式使用 `--mode dev`，正式部署前需核对构建模式和 API 地址。
- [NestJS 后端配置](../../../apps/server/package.json)：需要持续运行的 Node.js 服务，使用 PostgreSQL、Redis、BullMQ 和 S3 兼容存储客户端。
- [基础设施 Compose](../../../docker-compose.yml)：已包含 PostgreSQL 18、Redis 8、MinIO 和存储初始化服务，未包含前端、后端及公网入口服务。
- [应用模块](../../../apps/server/src/app.module.ts)：加载数据库、会话 Redis、任务队列和上传模块。
- [存储适配器](../../../apps/server/src/modules/upload/storage/minio-storage.adapter.ts)：启动时检查存储桶，完整运行上传功能需要可用的 S3 兼容存储。

以每月不超过 50 元的总预算筛选阿里云大陆地域服务器，并核对公网 IP、备份及额外资源费用。2026-10-27 读取[阿里云官方 ECS 活动页](https://www.aliyun.com/daily-act/ecs/activity_selection)，页面列出 2 核 2GB、3Mbps 固定带宽、40GB ESSD Entry 系统盘，标注“续费 99 元 1 年”和“限购 1 台”；99 元年费折合每月 8.25 元。页面首购价格动态区域未返回明确金额，不能据此认定用户账号首购也是 99 元。实际首购、地域库存、账号资格和续费规则以登录购买页为准。

个人演示起步建议：单台 Linux 服务器，先评估 2 核 CPU、2GB 内存，使用 Nginx 或 Caddy 提供静态页面和 API 反向代理，后端、数据库、Redis、MinIO 集中部署。当前服务数量较多，2GB 内存是否足够需要实际启动和演示验证；本地或 CI 构建后上传产物，避免在小内存服务器上同时构建。若内存不足，再比较预算内的 4GB 套餐，不把 4GB 作为本次演示必须购买的配置，也不声称 2GB 已验证可用。

期望入口为服务器公网 IP，由 Nginx 或 Caddy 提供页面和同源 API 反向代理，不要求域名解析；该技术设计不表示阿里云大陆未备案公网 Web 访问已获允许。先依据[接入核查](./阿里云IP访问核查.md)解决备案或个人封闭测试适用条件，再安排相应演示访问。HTTPS 不作为目前尚未确认的强制演示要求；若页面功能依赖安全上下文，或需要传输真实敏感数据，再配置支持公网 IP 的受信任 HTTPS 证书并验证续期。

通过用户实际使用的中国大陆网络访问并验证速度。使用 IP 本身不会显著提升访问速度，选型仍以服务器地域、线路、带宽和实际访问结果为准。

文件上传是现有功能，3Mbps 可先用于页面和小文件演示，大文件速度是否满足需要另测。购买前核对上传／下载方向及限额，公网入口与对象存储尽量保持同地域；演示数据按需持久化并保留副本，不引入尚未要求的生产可用性或高可用采购范围。

## 部署验收目标（待实施时细化）

- 在服务商允许的接入方式下，从用户实际使用的网络通过公网 IP 访问，页面刷新、登录、业务 API 和所需上传演示正常；若启用 HTTPS，补充证书、浏览器信任及续期验证。个人演示验收不代表正式生产就绪。
- API 使用正确的公网地址或同源路径，生产环境变量与构建产物相符，服务可在重启后恢复。
- 数据库、Redis 和存储管理入口不直接暴露给普通公网用户；演示数据和文件按用户需要持久化及保留副本。
- 通过目标地区的实际访问验证后再评价速度；本次代码阅读不作为公网连通、性能或生产就绪的验收证据。
