# NestJS 独立模板交付记录

状态：已交付。日期：2026-10-20。

## 交付内容

- 新模板：[template-nestjs](../../../../template-nestjs/README.md)，后端代码位于根目录 `src/`，必要共享类型和工具保留在模板自己的 `packages/shared/`。
- 保留原认证、权限、组织、企业、项目、成员、菜单、审计、上传、队列、数据库迁移和测试功能。
- 补齐独立 TypeScript 配置、具体依赖版本、pnpm workspace、锁文件、SWC / Nest 配置、环境示例、Docker Compose 与开发约定。
- 接入 `create-bubbles` 的 NestJS 分类和 `nestjs` 选项，模板复制与发布过滤依赖、缓存及构建结果。
- 不复制实际环境文件，不改动来源后端业务，不删除目标目录已有依赖残留。

## 使用入口

按照新模板的 [运行说明](../../../../template-nestjs/.spaces/01.模板使用/NestJS模板/运行说明.md) 创建 `.env`、生成 Session Pepper、安装依赖、启动本地服务并执行迁移。后端使用 Redis Session 的 Bearer Token，Swagger 继续保留。

本次没有发布 npm 包、提交 Git、更改业务数据库或启动外部服务。完整验证结果与边界见 [测试报告](./测试报告.md)。
