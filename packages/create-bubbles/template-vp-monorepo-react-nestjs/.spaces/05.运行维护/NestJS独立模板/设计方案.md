## 目录与依赖

将 `apps/server` 的有效项目文件复制到 `../template-nestjs/` 根目录，`packages/shared` 保持为模板内的本地共享包，由最小 pnpm workspace 管理。依赖版本取自来源项目现行 catalog，模板内自行声明，不依赖外层仓库。构建、开发、检查、测试和管理员初始化脚本先构建共享包；共享包源码变化后重新构建。

根 TypeScript 配置移除 `../../tsconfig.base.json` 的外部继承，共享包补齐自身编译配置。保留 SWC 装饰器编译、路径别名、文件哈希 Worker 资产和原有测试配置。Swagger 标题改为 NestJS 后端模板 API，接口协议不变。
