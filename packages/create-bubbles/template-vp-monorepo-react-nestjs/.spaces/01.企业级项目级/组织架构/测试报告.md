## 4. 浏览器验收缺口

独立企业 P0 实现与迁移专项已完成；完整真实浏览器验收仍有以下缺口。邀请协议后置，禁用入口版本不需等待该协议，邀请业务另行确认后再验证：

1. 企业／项目工作空间入口、A→B→C 快速切换和同路由权限重校验，确认旧树、筛选、分页、选择和迟到请求均不污染新作用域。
2. 组织单元创建、同树移动、重命名、停用／恢复后，当前节点和已加载后代的 fullPath、depth、effective 与 hasChildren 正确刷新。
3. 组织成员选择器的服务端分页、姓名／完整账号搜索、同名账号、同名组织完整路径、标签独立、去重和禁选原因。
4. GlobalAccountSelect 只在平台授权场景出现；企业成员页面提供直接注册和邀请两个入口，当前只验收入口边界与直接注册流程；邀请管理和接受流程须在协议确认后另行补充。项目成员选择只返回所属企业有效成员、按 `userId` 提交并排除已加入者。
5. 仅查看、可分配、可维护等典型角色下，页面按钮、筛选能力和服务端 403／404 一致。
6. 同一页面连续打开 A→B 弹窗时，A 的迟到成功、失败和 `finally` 均不能覆盖 B 的内容或 loading。
