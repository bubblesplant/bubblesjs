# 组织职责开关

状态：已实施并通过专项复验。职责开关 19 项、组织 26 项及岗位 28 项浏览器检查、Web 全量 264 项与构建均通过。

沿用既有选择器浅紫已选区、白色标签、固定双栏和内部滚动。默认 `enableDuties=false`，左侧只有组织列；设为 `true` 才显示“职责”下拉框。业务单调用无成员依赖；成员归属编辑显式启用。

规则和输出类型见[需求](../../需求文档.md#组织选择器职责开关)、[设计](../../设计方案.md#66-可复用组织选择与职责开关)和[技术契约](../../技术契约.md#组织选择职责参数)。界面来自实际组件与虚构组织；输出来自真实点击确定时触发的 onConfirm。

| 参数        | 桌面                       | 390px 窄屏                         | 实际确认输出                                                   |
| ----------- | -------------------------- | ---------------------------------- | -------------------------------------------------------------- |
| 默认／false | [关闭职责](./关闭职责.png) | [关闭职责窄屏](./关闭职责窄屏.png) | [string 数组](../../测试证据/组织职责开关/without-duties.json) |
| true        | [开启职责](./开启职责.png) | [开启职责窄屏](./开启职责窄屏.png) | [组织关系数组](../../测试证据/组织职责开关/with-duties.json)   |

关闭职责的实际输出：

```json
["org-demo-1", "org-demo-2"]
```

开启职责的实际输出：

```json
[
  { "organizationUnitId": "org-demo-1", "duty": "leader" },
  { "organizationUnitId": "org-demo-2", "duty": "member" }
]
```
