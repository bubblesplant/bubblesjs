# 岗位选择布局

状态：已实施并通过浏览器复验。

企业级与项目级成员岗位任职编辑沿用[组织选择视觉](../组织选择布局/README.md)。桌面左侧搜索名称／编码并勾选岗位，右侧 280px 浅紫已选区、白色标签按内容排列并自动换行，列表使用 `overflow: auto`；窄屏上下排列且已选区固定 160px。岗位名称与编码同时展示，选择数量不改变主体高度。

规则见[需求文档 FR-05](../../需求文档.md#fr-05-独立岗位)和[设计方案](../../设计方案.md#65-成员岗位任职编辑)。以下截图由真实组件使用明显虚构数据生成，已核对标签同行、自动换行、窄屏布局和确认按钮。
