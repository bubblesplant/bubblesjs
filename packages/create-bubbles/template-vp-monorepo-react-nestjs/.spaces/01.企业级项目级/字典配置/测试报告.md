## 实际验证内容

后端使用本机随机命名的隔离 PostgreSQL 数据库，完整执行迁移并重复执行确认幂等，通过真实 AccessService、DictionariesService、Nest/Fastify 校验、序列化、异常过滤及守卫验证：

- 普通企业成员无平台角色也可读取平台共享选项，但不能访问平台配置管理。
- 三范围同编码互不混用，企业／项目资格隔离，已知 UUID 不能跨范围修改。
- 管理 HTTP 创建、搜索、编辑返回公开字段；错误请求得到 400、无会话得到 401、越权得到 403、无效字典得到 404。
- 同归属重复编码和不匹配的项目归属被数据库拒绝；并发保存只有一个版本成功，审计与更新一致。
- 已保存选项值不能修改／移除；全部选项停用返回空数组，字典停用返回 404。
- Swagger 覆盖三类管理路由与独立选项接口；真实 HTTP 顶层数组按单项 Schema 正确序列化。

Web 缓存测试覆盖精确归属键、同键合并、TTL、容量、空结果、失败重试、本地搜索与返回副本；退出／换号／主动失效前的迟到响应不能返回或回填。持久化覆盖身份、结构、有效期、异常存储和配额失败删除旧快照。

选择字段测试使用真实 ProFormSelect 和真实缓存核心，验证多字段共享、打开下拉复用、过期重取、主动失效重取、失败提示及重试、搜索不额外请求，以及切换字典后空结果清理。

模拟接口的 8 组 Edge 检查访问实际前端应用，全部 `/api/` 请求由明显虚构的数据响应，不写入账号或业务数据。检查三范围菜单／路由／列表，平台新增与选项预览，刷新后恢复 sessionStorage 且不重复取选项，编码和值只读、提交版本号、保存后选项刷新；企业和项目各自编辑名称／排序、新增空字典，重复打开表单状态重置。

另通过 [完整服务工具](./工具/e2e/run.mjs)在 Edge 155.0.4283.62 上执行 11 组验收。环境工具创建随机隔离 PostgreSQL 库、执行全部迁移，启动完整 AppModule 和独立 Vite 前端；公开注册三个虚构账号，通过官方初始化命令设置平台管理员，再真实登录、创建企业和项目。Redis 使用本机真实服务，前端使用既有 Vite 代理，未模拟或拦截 HTTP。

- 平台管理员通过真实页面登录，Redis 确实存在会话；平台新增／编辑、企业新增／编辑、项目新增／编辑均通过界面操作，并查询数据库验证版本和选项落库。
- 真实 ProFormSelect 读取选项，刷新后从 sessionStorage 恢复，选项请求数不增加；编辑保存后对应缓存失效，预览重新请求并显示新名称。
- 企业账号无平台角色仍可调用统一方法读取平台共享选项；访问平台管理接口返回 ACCESS.FORBIDDEN（403）。三范围使用相同编码，分别返回本范围选项。
- 企业、项目过期版本保存返回 ACCESS.VERSION_CONFLICT（409），修改历史选项值返回 DICTIONARY.ITEM_VALUE_IMMUTABLE（409）；无企业成员资格的外部账号读取私有选项返回 ACCESS.NOT_FOUND（404），沿用既有权限服务的隐藏归属规则。
- 三范围创建与编辑均产生真实数据库审计记录。正常退出撤销 Redis 会话，旧令牌请求返回 401；只删除字典专属 sessionStorage，保留无关键，换号不继承旧缓存。
- 浏览器全程没有页面异常或 API HTTP 5xx。最终记录 19 次工具直接 HTTP 调用、7 次浏览器选项请求；这些次数包含初始化和校验，不作为独立用例数。

## 执行方式

以下使用项目约定的 `vp`，在对应目录执行。报告参数可参照现有 JSON 证据另行添加。

```powershell
# apps/server；仅允许本机隔离库，测试结束删除本次数据库
$env:RUN_DICTIONARY_INTEGRATION = 'true'
vp test test/dictionaries test/error-catalog.spec.ts test/access/access-policy.spec.ts test/schema/native-schema.spec.ts

# apps/web
vp test test/dictionary test/workspaces test/router test/workspace-requests.spec.ts test/workspace-navigation-boundary.spec.tsx
vp test test/request.spec.ts test/workspace-navigation.spec.ts --config='../../.spaces/01.企业级项目级/字典配置/工具/regression/config.ts'

# packages/shared
vp test

# 仓库根目录；浏览器默认复用 localhost:9999 的现有前端服务
vp exec node '.spaces/01.企业级项目级/字典配置/工具/browser/run.mjs'
vp exec node '.spaces/01.企业级项目级/字典配置/工具/regression/check-types.mjs'

# 仓库根目录；需先构建 shared、server，使用本机 PostgreSQL／Redis 配置
# 自动创建隔离库、虚构账号及独立前后端服务，finally 中清理，不复用用户业务库
vp exec node '.spaces/01.企业级项目级/字典配置/工具/e2e/run.mjs'
```

Web、Server 分别执行 `vp exec tsc --noEmit`、`vp run build`。Shared 构建执行 `vp run build`。lint 和格式仅检查本次相关路径，避免修改其他功能的在途变更。

## 初次失败与修复说明

- 真实 HTTP 暴露 Nest 对顶层数组逐项序列化的行为，选项接口已改用单项响应 Schema，并通过集成复测。
- 真实 ProFormSelect 暴露字段加载失败提示未透传，现通过 `formItemProps.extra` 显示，保留表单自身校验；组件测试已覆盖重试。
- 新平台写权限使共享目录测试的管理员权限预期需要增加两个权限，现已补齐并通过。
- [Web 初次回归](./测试证据/web-tests.json)的两个既有文件因 Node 无 localStorage 而无法加载；[直接切换 happy-dom](./测试证据/web-environment-regression.json)又使 Axios 走浏览器传输，引起跨源失败。这两份是失败历史证据，不计入通过结果。最终使用 [Node 专用配置](./工具/regression/config.ts)保留真实 HTTP，仅替换与传输无关的国际化初始化，17 项全部通过；相关业务代码和原测试均未为此改动。
- 浏览器工具已修正 API URL 匹配、带图标按钮的可访问名称、列表等待与中文弹窗关闭定位；最终结果以 browser.json 为准。截图禁用动画后重新采集，避免动画中间态。
- 完整服务工具初次执行修正了 Vite+ CommonJS 导出读取、错误结构的 code 字段以及无成员资格应返回 404 的断言；未修改业务实现。最终完整结果以 e2e.json 为准，各次执行均完成隔离资源清理。
