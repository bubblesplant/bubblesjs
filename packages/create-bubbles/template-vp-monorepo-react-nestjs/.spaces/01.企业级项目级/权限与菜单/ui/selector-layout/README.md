# 账号与角色选择器布局

## 已确认样式设计

状态：2026-11-04 用户已确认设计图，已实施并通过复验。账号、角色和成员选择器按本稿统一视觉；下方截图已更新为本轮真实实现。

- [设计图 PNG](./选择器样式提案.png)：完整角色选择弹窗，以及角色标签、账号／成员标签和空选择三个细节场景。
- [设计稿 HTML](./选择器样式提案.html)：可复现的独立设计画板，不接入业务页面。
- [渲染工具](../../工具/selector-design/render.mjs)：使用本机 Edge 渲染 PNG，校验标签同行和自动换行。

设计方向：沿用项目紫色，白色弹窗配浅紫已选面板，白色胶囊标签按内容宽度排列；弱化侧栏边框，数量使用紧凑徽标，清空操作与标签移除保持清晰。桌面左表右选，面板内部滚动；角色、账号和成员复用同一结构。

配色：主色 `#7861CC`、文字 `#26243B`、次要文字 `#8A869D`、已选底色 `#F7F5FD`、分隔线 `#EEEBF5`、画布 `#F0F1F6`。字体使用清晰的中文无衬线字，弹窗标题 23px、正文 14px、辅助文字 12px。标签不拉伸，多行从顶部连续排列；长名称在标签内换行。

设计稿作为本轮实施依据；实际弹窗按业务内容适配，桌面已选区宽 280px、窄屏高 160px。完整角色弹窗展示整体层次，账号／成员标签沿用同版样式。

设计稿生成记录：先使用内置 imagegen 生成视觉概念，提示要求为紫色企业管理选择器、左侧表格、右侧浅紫固定容器、白色标签横向换行、角色／成员／空态延伸。工具预览未返回本地文件，因此依照同一方案用独立 HTML／CSS 画板渲染并归档 PNG，保证中文文案准确。设计阶段未使用付费 CLI/API 回退或修改业务组件。已检查本地图片可解码且画面完整；内容均为虚构演示数据。
