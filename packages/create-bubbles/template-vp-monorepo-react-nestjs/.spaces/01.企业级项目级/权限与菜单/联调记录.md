## 2026-09-17 成员接入增量联调范围

- 平台开通企业和设置企业管理员使用 `GlobalAccountSelect`，稳定值为 `userId`，请求字段为 `administratorUserId`；服务端仍需按提交时状态复核账号有效性。
- 企业直接注册新账号并加入企业已经确认，需要联调账号、企业成员关系、默认 member 角色和审计同事务提交，以及账号冲突时不留下部分数据。
- 企业邀请已进入独立增量联调范围：列表、创建、撤销、重发、接受 5 个端点；不绑定账号的 7 天一次性 token；数据库仅存 SHA-256 摘要；`expired` 由有效期派生；创建／重发只返回一次原始 token，重发后旧链接立即失效。
- 接受流程需联调未登录先登录／注册并保留安全站内 `next`、返回后主动确认且页面不自动提交；同账号重复接受幂等，其他账号复用、过期、撤销、已有成员、停用企业和版本冲突按契约拒绝。列表、日志、异常和审计不得泄露原始 token 或摘要；首期不验证自动邮件发送。
- 项目添加成员使用所属企业成员候选，只返回有效且尚未加入当前项目的成员；选择和提交稳定 `userId`，服务端在事务内再次校验账号、企业成员资格、状态和重复关系。
- 本节记录已确认契约对应的待联调目标，不等同于通过证据。Shared、Server、Web、真实 PostgreSQL 和浏览器流程完成后，须把实际命令、数量与失败回流补入本记录及测试报告；代码存在或静态契约确认均不能记为邀请能力已通过。

## 数据隔离

- 本次验收独立创建临时 PostgreSQL 18 和 Redis 8 容器，仅监听 `127.0.0.1`，端口分别为 15432 和 16379。
- 容器名称为 `codex-enterprise-01a085-pg` 与 `codex-enterprise-01a085-redis`，数据库为 `enterprise_test`。
- 测试 API 实际监听 `http://127.0.0.1:3301`，Web 监听 `http://127.0.0.1:5301`，通过 `/api` 代理到测试 API；原有开发数据库、Redis 及其数据不修改。
- 独立 MinIO 容器 `codex-enterprise-01a085-minio` 监听本机 19000，使用单独测试 bucket 验证原有上传，不改现有对象存储。
- 测试数据库密码与会话密钥运行期随机生成，仅在系统临时配置中传递，不写入仓库或报告。测试账号亦按运行期生成。
- 正式交付需提供迁移和初始化说明；测试环境初始化成功不代替现有库兼容验证。

测试启动器为 `scripts/with-enterprise-test-env.mjs`，参数依次为临时 JSON 配置绝对路径、工程内工作目录、可执行文件及其参数。它检查测试数据库名称与本机地址，将配置仅注入子进程，不打印密钥。真实集成测试需直接调用包目录的测试命令，避免任务编排器过滤环境变量。

