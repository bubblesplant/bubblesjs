## 2026-09-17 待实施与待复验范围

- 平台创建企业、设置或更换企业管理员统一使用 `GlobalAccountSelect`，表单保存 `userId` 并提交 `administratorUserId`，不再把账号字符串作为关系标识。
- 企业成员页当前已确认的新增能力是“直接注册新账号并加入企业”，提交姓名、完整账号和密码；不能继续使用完整账号搜索并直接拉入既有平台账号。
- 企业成员页还须提供不绑定账号的 7 天一次性邀请管理：创建／重发后仅展示一次完整链接供复制，列表展示 `pending | expired | accepted | revoked`，pending 可撤销，pending 或已过期邀请可重发并使旧链接立即失效。首期不自动发送邮件。
- `/member-invitations/accept?token=...` 为公开可达的接受页：未登录者可选择登录或注册并通过安全站内 `next` 返回；返回后仍须由当前账号点击确认，页面加载不得自动提交 token。
- 项目成员页使用 `OrganizationMemberSelector` 的 `purpose=addProjectMember`，只展示所属企业有效且未加入当前项目的成员，选择和提交均为 `userId`；不展示组织、岗位或角色标签。
- 已确认的管理员选择、企业直接注册、邀请管理／接受页和项目成员候选流程需补组件测试、请求层测试和真实浏览器回归；完成前不得沿用下方 2026-09-10 构建／测试结果宣称当前入口已通过。

## 实现范围

- `src/pages/register`、`src/pages/login/index.tsx`：公开注册、登录、注册成功账号提示，以及登录后的工作空间入口。
- `src/pages/workspaces`：按服务端有效身份展示企业、项目和平台工作空间。无企业普通账号提示联系企业管理员获取邀请链接，并说明登录后需主动确认加入；不得要求用户提供完整账号供管理员直接挂接。有效平台身份仍保留平台入口。
- `src/pages/access`：工作台、企业开通与启停、项目创建与启停、管理员补任与更换、账号与成员管理、企业邀请列表／创建／撤销／重发、角色分配、自定义角色与权限树、资料、三套菜单编辑、废弃权限清理预览与执行、审计筛选与分页。
- `src/pages/member-invitations`：解析 URL token，展示登录／注册或主动确认状态；401 回登录时保留安全站内 `next`，成功后进入工作空间。错误展示沿用服务端公开错误，不泄露 token 摘要或企业外数据。
- `src/pages/access/components`：通过 `show/hide` 暴露弹窗操作，所有写操作使用共享契约 DTO。内置角色定义只读；权限树保留页面和操作的依赖关系及全选、半选行为。
- `src/router`：17 个静态管理页面注册，路由按功能拆入 `modules`，父级 scope middleware 获取作用域上下文，叶子 access middleware 校验页面权限；未知页面显示 404。页面 403 不会清空其他可用导航；空间首页无读权限时，优先进入可见菜单中的已授权静态页面。默认入口对无平台或额外企业职责的单项目成员直接进入项目，其余进入工作空间；明确选择的工作空间和页面不被分流覆盖。示例页面不出现在生产菜单。
- `src/router/lazy-load`、`src/App.tsx`：使用 `lazyLoad('access', 'home')` 等相对 pages 的路径统一懒加载，并在 App 中只保留一个 `RouteTransition`。
- `src/layouts/WorkspaceLayout/index.tsx`、`workspace.css`：三种作用域布局、具体企业／项目名称、导航和切换；切换期间禁用旧页面交互，进入新空间时重建业务子树；权限刷新时隐藏页面并保留表单输入。
- `src/utils/request/workspace.ts`：沿用现有 alova 请求封装；管理请求禁止缓存，取消旧请求，使用用户、作用域和请求代次阻止迟到结果。旧 401 不得退出新账号，旧 403 不得刷新新空间。当前业务 403 刷新一次，access 403 不递归。
- `test/workspace-requests.spec.ts`、`test/workspace-navigation.spec.ts`、`test/router`：权限导航、请求竞态、入口分流及真实 React Router memory 导航回归测试；原 loader 测试迁移至 middleware 测试。

## 联调边界

- 页面直接调用真实 API，没有使用 mock 数据。共享类型与纯工具统一从 `shared/types`、`shared/utils` 导入。
- 企业项目列表的管理员设置使用已同步契约的 `GET /companies/:companyId/projects/:projectId/administrators`，支持读取停用项目的显式项目管理员，避免将企业隐式管理员当作待替换的项目身份。
- React Router 当前安装版本为 8.3.1，使用原生 Data Mode middleware。工作空间列表及各空间权限保存在 `pages/workspaces/state.ts`，页面随导航或重新校验完成后读取。布局通过 `Outlet context` 向子页面提供同一份权限；缺数据时显示加载态，避免撤权过渡中的旧页面读取空权限。不再订阅路由状态或维护导航快照。
- 开发前端默认 API 前缀为 `/api`；隔离联调环境由主控启动，前端端口 5301，后端端口 3301。前端代理通过 `VITE_API_URL` 配置。
- Playwright 真实页面、后端接口和数据库事务验收由主控及 QA 独立执行，结果应写入最终测试报告，不能用本交接中的静态检查替代。
