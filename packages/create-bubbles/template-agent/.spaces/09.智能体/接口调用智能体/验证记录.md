## 发现与修正

1. Skills 参考资料原来按整个技能目录检查范围，`references/../SKILL.md` 可以回到正文。现改为以真实 references 目录为读取边界，并检查目录链接没有越出技能目录。
2. 一个 ToolNode 节点内并行运行多个会提问的子图时，本次版本组合只向宿主返回先到的中断。现按第七课实现，用 Send 为每个工具调用建立独立图任务，框架可收集两个交互 ID，并在全部回答后汇合。
3. 测试服务最初复用了同一 AI 消息 ID，导致消息 reducer 替换旧回复；现使用不同响应 ID。此项是测试响应修正。
4. 当前 OpenAI 结构化输出使用 response_format 时不一定发送函数工具；本地服务同时覆盖 JSON schema 形式与工具形式，未强制某一种默认调用路径。

最终示例包含以上修正，验证结果以当前 JSON 为准。
