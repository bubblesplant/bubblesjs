# 第十课：封装成可初始化、可组合的 Agent

状态：完整教学实现资料。前置：[第九课](./09.子代理与等待.md)。[返回课程入口](../学习教程.md)。

## 目标与边界

现在从已经理解的图中提炼组件式 API，支持：

- 初始化传入 id、description、system prompt、主备模型、Skills 目录、MCP 列表及本地工具。
- 同一实例独立运行，或作为其他 Agent 的子代理；注册能力后，由执行中的模型决定委派什么任务、调用几次。
- 连续会话、可信 context、候选选项打断、原 run 恢复、状态查询。
- 共享模型步骤／token 计数、模型并发、子任务总数、深度、活跃执行时限与累计用户等待时限。
- 执行事件、取消及自己拥有的 MCP 连接释放。

这是一套后端教学运行时，代码全部在下面；不是项目已经上线的业务服务。工具示例都是只读或纯计算。写操作确认、幂等执行账本、跨进程恢复、长期记忆、HTTP／UI 和生产审计仍需在正式实施时按设计方案补齐。

学习脚本共用文件继续放在 `scripts/agent-learning/common/`；未来抽成生产包时，遵守项目共享类型及工具目录规则，不把模型密钥代码暴露给前端。

## 1. 先实现整棵调用树共用的执行预算

文件：`common/execution.mjs`。它不依赖模型，只管理时间、并发和统计。

<!-- file: common/execution.mjs -->

```javascript
import { randomUUID } from 'node:crypto'

const executions = new Map()

/** 从可信运行编号取得进程内预算，不把 context 或凭证放进模型消息。 */
export function getExecution(config) {
  const execution = executions.get(config.configurable?.executionId)
  if (!execution) throw new Error('运行上下文不存在或已结束')
  execution.signal.throwIfAborted()
  return execution
}

/** 创建父子共享的预算与取消控制；活跃计时在图返回 waiting_input 后暂停。 */
export function createExecution({ limits, context, signal, onEvent }) {
  signal?.throwIfAborted()
  const controller = new AbortController()
  const id = randomUUID()
  const waiters = []
  let active = 0
  let activeAt
  let waitingAt
  let activeTimer
  let waitTimer
  let activeMs = 0
  let waitedMs = 0

  const execution = {
    id,
    context,
    limits,
    signal: controller.signal,
    steps: 0,
    attempts: 0,
    tokens: 0,
    tasks: new Set(),

    /** 观察者失败不能改变任务结果；不要在事件中输出密钥和完整配置。 */
    emit(type, details = {}) {
      try {
        const observed = onEvent?.({ type, executionId: id, ...details })
        if (observed?.catch) observed.catch(() => console.error('事件观察者失败'))
      } catch {
        console.error('事件观察者失败')
      }
    },

    /** 开始一次活跃执行；回答问题不会重置既有时间预算。 */
    start() {
      controller.signal.throwIfAborted()
      clearTimeout(waitTimer)
      if (waitingAt !== undefined) {
        waitedMs += Date.now() - waitingAt
        waitingAt = undefined
      }
      if (waitedMs >= limits.maxWaitMs) throw new Error('累计等待时间超限')
      const remaining = limits.timeoutMs - activeMs
      if (remaining <= 0) throw new Error('活跃执行时间超限')
      activeAt = Date.now()
      activeTimer = setTimeout(() => execution.abort('活跃执行超时'), remaining)
      activeTimer.unref?.()
    },

    /** 停止本段活跃计时，进入等待时使用单独的累计等待预算。 */
    stop(waiting = false) {
      clearTimeout(activeTimer)
      if (activeAt !== undefined) {
        activeMs += Date.now() - activeAt
        activeAt = undefined
      }
      if (waiting) {
        waitingAt = Date.now()
        waitTimer = setTimeout(
          () => execution.abort('累计用户等待超时'),
          Math.max(1, limits.maxWaitMs - waitedMs),
        )
        waitTimer.unref?.()
      }
    },

    /** 仅对真正的模型请求占用名额，不让等待子任务的父节点占满名额。 */
    async acquireModel() {
      controller.signal.throwIfAborted()
      while (active >= limits.maxConcurrentModels) {
        await new Promise((resolve, reject) => waiters.push({ resolve, reject }))
        controller.signal.throwIfAborted()
      }
      active++
      let released = false
      return () => {
        if (released) return
        released = true
        active--
        waiters.splice(0).forEach((item) => item.resolve())
      }
    },

    /** 取消后唤醒并发等待者；远端已经发生的副作用不会自动回滚。 */
    abort(reason, cancelled = false) {
      const error = new Error(reason)
      error.name = cancelled ? 'CancelledError' : 'ExecutionLimitError'
      controller.abort(error)
    },

    usage() {
      return {
        steps: execution.steps,
        attempts: execution.attempts,
        tokens: execution.tokens,
        tasks: execution.tasks.size,
        activeMs: activeMs + (activeAt === undefined ? 0 : Date.now() - activeAt),
      }
    },

    /** 终态释放计时器、外部取消监听与预算注册。 */
    dispose() {
      execution.stop()
      clearTimeout(waitTimer)
      signal?.removeEventListener('abort', forwardAbort)
      executions.delete(id)
    },
  }

  /** 将调用方取消传播到该运行及其所有子调用。 */
  function forwardAbort() {
    execution.abort('调用方取消', true)
  }
  controller.signal.addEventListener(
    'abort',
    () => {
      waiters.splice(0).forEach((item) => item.reject(controller.signal.reason))
    },
    { once: true },
  )
  signal?.addEventListener('abort', forwardAbort, { once: true })
  executions.set(id, execution)
  return execution
}
```

token 统计采用服务返回的 usage，超过阈值时停止后续执行。单次请求可能已经产生超出剩余预算的 token，服务不返回 usage 时也无法准确计数，因此这是观测后的执行上限，不是精确的预付费硬限额。需要严格费用控制时还要结合供应商侧额度、输入估算及每次输出预算。

等待用户时图已经交回宿主，因此不占模型并发名额。父代理等待子图时也不占模型名额；真正的子模型请求使用同一个闸门，避免“父节点占满并发、子节点永远排队”的死锁。

## 2. 把模型、工具、子图与生命周期组装起来

文件：`common/agent.mjs`。先通读，再分段手写；不要第一次看到就背整段代码。这里的 root graph 用于独立会话，child graph 用于父运行中的一次委派，两者共用能力配置。

<!-- file: common/agent.mjs -->

```javascript
import { randomUUID } from 'node:crypto'
import { tool } from '@langchain/core/tools'
import { MemorySaver, Command } from '@langchain/langgraph'
import { z } from 'zod'
import { createModel } from './model.mjs'
import { loadSkillTools } from './skills.mjs'
import { openMcp } from './mcp.mjs'
import { buildAgentGraph } from './graph.mjs'
import { createAskUserTool, validateAnswer } from './interaction.mjs'
import { createExecution, getExecution } from './execution.mjs'
import { messageText } from './text.mjs'

const defaults = {
  maxSteps: 20,
  maxTokens: 20_000,
  maxDepth: 3,
  maxTasks: 8,
  maxConcurrentModels: 3,
  timeoutMs: 120_000,
  maxWaitMs: 600_000,
}
const terminalStatuses = new Set(['completed', 'failed', 'cancelled'])

/** 初始化教学 Agent；MCP 是本实例拥有的资源，传入的子 Agent 是借用的资源。 */
export async function createLearningAgent(options) {
  const {
    id,
    description,
    systemPrompt,
    models: modelSettings,
    tools = [],
    skills = {},
    mcpServers = {},
    subAgents = [],
    interaction = { enabled: true },
    policy = {},
    onEvent,
    inputSchema = z.string().min(1),
    outputSchema,
  } = options
  if (!/^[a-zA-Z0-9_-]{1,40}$/.test(id)) throw new Error('Agent id 格式无效')
  if (!description?.trim() || !systemPrompt?.trim()) throw new Error('职责描述和系统提示词不能为空')
  if (new Set(subAgents.map((agent) => agent.id)).size !== subAgents.length) {
    throw new Error('子代理 id 重复')
  }
  const limits = { ...defaults, ...options.limits }
  for (const [name, value] of Object.entries(limits)) {
    const minimum = name === 'maxDepth' ? 0 : 1
    if (!Number.isSafeInteger(value) || value < minimum) throw new Error('限额无效：' + name)
  }
  const clients = [modelSettings.primary, ...(modelSettings.fallbacks ?? [])].map(createModel)
  const records = new Map()
  const locks = new Map()
  const brokenThreads = new Set()
  let closed = false
  let mcp = { tools: [], close: async () => {} }

  /** 宿主必须先验证身份；这里只校验必要字段并形成隔离键，不提供登录鉴权。 */
  function ownerKey(context) {
    if (!context?.tenantId || !context?.userId) throw new Error('缺少可信租户或用户身份')
    return JSON.stringify([context.tenantId, context.userId])
  }

  /** 自定义输入 schema 真正参与校验；对象输入序列化为消息内容。 */
  function inputText(input) {
    const value = inputSchema.parse(input)
    return typeof value === 'string' ? value : JSON.stringify(value)
  }

  /** schema 是结果契约；模型返回无效 JSON 或字段不符时，本运行失败。 */
  function outputValue(reply) {
    return outputSchema ? outputSchema.parse(JSON.parse(reply)) : reply
  }

  /** 查询、恢复和取消均验证归属，不能只凭 runId 访问其他用户的任务。 */
  function ownedRecord({ runId, context }) {
    const record = records.get(runId)
    if (!record || record.owner !== ownerKey(context)) throw new Error('运行不存在或无权访问')
    return record
  }

  /** 对外只交付状态、交互和结果，避免暴露图配置及内部模型凭证。 */
  function view(record) {
    return {
      runId: record.runId,
      threadId: record.threadId,
      status: record.status,
      interactions: (record.interrupts ?? []).map((item) => ({ id: item.id, ...item.value })),
      reply: record.reply,
      output: record.output,
      error: record.error,
      usage: record.execution.usage(),
    }
  }

  /** 终态释放会话占用；失败的 thread 不继续拼接可能未闭合的工具消息。 */
  function finish(record, status, error) {
    if (terminalStatuses.has(record.status)) return
    record.status = status
    record.interrupts = []
    if (error) record.error = { name: error.name, message: error.message }
    if (status !== 'completed') brokenThreads.add(record.threadKey)
    if (status !== 'completed' && !record.execution.signal.aborted) {
      record.execution.abort('运行终止，停止其余子调用', status === 'cancelled')
    }
    locks.delete(record.threadKey)
    record.execution.stop()
    record.execution.emit('run.' + status, { agentId: id })
    record.execution.dispose()
  }

  const hooks = {
    /** 整棵调用树共用计数，取得模型名额后再计数，避免并发越过步骤上限。 */
    async beforeModel(config) {
      const execution = getExecution(config)
      const release = await execution.acquireModel()
      if (
        execution.steps >= execution.limits.maxSteps ||
        execution.tokens >= execution.limits.maxTokens
      ) {
        release()
        throw new Error('共享模型步骤或 token 预算已耗尽')
      }
      execution.steps++
      execution.emit('model.started', { agentId: id, step: execution.steps })
      return release
    },

    /** fallback 增加请求尝试数，不会重做前面已经完成的工具。 */
    onAttempt({ index, config }) {
      const execution = getExecution(config)
      execution.attempts++
      execution.emit('model.attempt', { agentId: id, modelIndex: index })
    },

    /** 使用供应商返回的 usage 观测总量；不把未知用量当成精确的零费用。 */
    afterModel({ reply, config }) {
      const execution = getExecution(config)
      const tokens = reply.usage_metadata?.total_tokens
      if (Number.isFinite(tokens)) execution.tokens += tokens
      execution.emit('model.completed', { agentId: id, tokens: tokens ?? null })
      if (execution.tokens > execution.limits.maxTokens) throw new Error('共享 token 预算超限')
    },

    /** 根代理权限继续约束子调用；子代理自己的策略只能进一步收紧。 */
    async beforeTools({ calls, config }) {
      const execution = getExecution(config)
      for (const call of calls) {
        for (const rule of new Set([execution.policy, policy])) {
          if (rule.allowToolNames && !rule.allowToolNames.includes(call.name)) {
            throw new Error('工具不在允许列表：' + call.name)
          }
          if (
            rule.authorize &&
            (await rule.authorize({
              agentId: id,
              toolName: call.name,
              context: execution.context,
            })) !== true
          )
            throw new Error('工具权限被拒绝：' + call.name)
        }
        execution.emit('tool.started', { agentId: id, toolName: call.name })
      }
    },
  }

  try {
    if (Object.keys(mcpServers).length) mcp = await openMcp(mcpServers)
    const skillTools = skills.directories?.length ? await loadSkillTools(skills.directories) : []
    const delegateTools = subAgents.map((child) =>
      tool(
        async ({ input }, config) => {
          const execution = getExecution(config)
          const depth = (config.configurable.depth ?? 0) + 1
          if (depth > execution.limits.maxDepth) throw new Error('子代理深度超限')
          // 同一工具在恢复时可能重放，用稳定调用标识避免重复计为新子任务。
          const key = JSON.stringify([config.configurable.checkpoint_ns, config.toolCall?.id])
          if (!execution.tasks.has(key)) {
            if (execution.tasks.size >= execution.limits.maxTasks) throw new Error('子任务总数超限')
            execution.tasks.add(key)
            execution.emit('task.started', { agentId: child.id, taskId: key })
          }
          const result = await child.invokeFromParent({
            input,
            config: { ...config, configurable: { ...config.configurable, depth } },
          })
          execution.emit('task.completed', { agentId: child.id, taskId: key })
          return typeof result === 'string' ? result : JSON.stringify(result)
        },
        {
          name: 'delegate_' + child.id,
          description: child.description,
          schema: z.object({ input: child.inputSchema }),
        },
      ),
    )
    const allTools = [
      ...tools,
      ...skillTools,
      ...mcp.tools,
      ...delegateTools,
      ...(interaction.enabled ? [createAskUserTool(id)] : []),
    ]
    const prompt = outputSchema
      ? systemPrompt +
        '\n最终回复必须只包含符合此 schema 的 JSON：' +
        JSON.stringify(z.toJSONSchema(outputSchema))
      : systemPrompt
    const graphOptions = { models: clients, tools: allTools, systemPrompt: prompt, hooks }
    const rootGraph = buildAgentGraph({ ...graphOptions, checkpointer: new MemorySaver() })
    const childGraph = buildAgentGraph(graphOptions)

    /** 执行新段或恢复段；等待用户时停止活跃计时，保留同一 run 与检查点。 */
    async function drive(record, input) {
      record.pending = (async () => {
        try {
          record.status = 'running'
          record.execution.start()
          const result = await rootGraph.invoke(input, record.config)
          record.execution.signal.throwIfAborted()
          if (result.__interrupt__?.length) {
            record.interrupts = result.__interrupt__
            record.status = 'waiting_input'
            record.execution.stop(true)
            record.execution.emit('run.waiting_input', { agentId: id })
          } else {
            record.reply = messageText(result.messages.at(-1))
            record.output = outputValue(record.reply)
            finish(record, 'completed')
          }
        } catch (error) {
          const reason = record.execution.signal.reason ?? error
          finish(record, reason.name === 'CancelledError' ? 'cancelled' : 'failed', reason)
        }
      })()
      await record.pending
      record.pending = undefined
      return view(record)
    }

    return {
      id,
      description,
      inputSchema,

      /** 新任务可使用既有 thread；有待答任务时必须先 resume 或 cancel。 */
      async run({ input, threadId = randomUUID(), context, signal }) {
        if (closed) throw new Error('Agent 已关闭')
        const text = inputText(input)
        const owner = ownerKey(context)
        const threadKey = JSON.stringify([id, owner, threadId])
        if (locks.has(threadKey)) throw new Error('该会话已有运行中或待回答的任务')
        if (brokenThreads.has(threadKey)) throw new Error('该会话曾失败或取消，请使用新的 threadId')
        const execution = createExecution({ limits, context, signal, onEvent })
        execution.policy = policy
        const record = {
          runId: execution.id,
          threadId,
          threadKey,
          owner,
          execution,
          status: 'created',
          config: {
            configurable: { thread_id: threadKey, executionId: execution.id, depth: 0 },
            signal: execution.signal,
            recursionLimit: limits.maxSteps * 3 + 10,
          },
        }
        records.set(record.runId, record)
        locks.set(threadKey, record.runId)
        execution.signal.addEventListener(
          'abort',
          () => {
            if (record.status === 'waiting_input') {
              const reason = execution.signal.reason
              finish(record, reason.name === 'CancelledError' ? 'cancelled' : 'failed', reason)
            }
          },
          { once: true },
        )
        execution.emit('run.started', { agentId: id })
        return drive(record, { messages: [{ role: 'user', content: text }] })
      },

      /** answers 是交互 ID 到原始答案的映射；拒绝漏答、重复恢复和越权恢复。 */
      async resume({ runId, answers, context }) {
        if (closed) throw new Error('Agent 已关闭')
        const record = ownedRecord({ runId, context })
        if (record.status !== 'waiting_input') throw new Error('当前运行不在等待回答')
        const ids = record.interrupts.map((item) => item.id)
        if (
          !answers ||
          Object.keys(answers).length !== ids.length ||
          Object.keys(answers).some((key) => !ids.includes(key))
        ) {
          throw new Error('答案必须与当前所有交互 ID 一一对应')
        }
        for (const item of record.interrupts) {
          validateAnswer({ question: item.value, answer: answers[item.id] })
        }
        record.interrupts = []
        record.execution.emit('run.resumed', { agentId: id })
        return drive(record, new Command({ resume: answers }))
      },

      getRun(request) {
        return view(ownedRecord(request))
      },

      /** 取消会传播到子图和模型；已发送的远端写操作不等于被撤销。 */
      async cancel(request) {
        const record = ownedRecord(request)
        if (!terminalStatuses.has(record.status)) {
          record.execution.abort('用户取消', true)
          await record.pending
        }
        return view(record)
      },

      /** 内部组合入口只接收父运行传来的可信 config；不对 HTTP 客户端暴露。 */
      async invokeFromParent({ input, config }) {
        if (closed) throw new Error('子 Agent 已关闭')
        getExecution(config)
        const result = await childGraph.invoke(
          {
            messages: [{ role: 'user', content: inputText(input) }],
          },
          config,
        )
        return outputValue(messageText(result.messages.at(-1)))
      },

      /** 关闭自己的运行和 MCP；调用方负责在父 Agent 之后关闭借用的子 Agent。 */
      async close() {
        if (closed) return
        closed = true
        const pending = []
        for (const record of records.values()) {
          if (!terminalStatuses.has(record.status)) {
            record.execution.abort('Agent 关闭', true)
            if (record.pending) pending.push(record.pending)
          }
        }
        await Promise.allSettled(pending)
        await mcp.close()
      },
    }
  } catch (error) {
    await mcp.close()
    throw error
  }
}
```

### 对照你的“前端组件”理解

| 初始化项                      | 在代码中真正产生的作用                               |
| ----------------------------- | ---------------------------------------------------- |
| `id / description`            | 标识能力；父模型能从委派工具说明选择能力             |
| `systemPrompt`                | 每次模型调用加入职责约束                             |
| `models`                      | 两种协议的独立配置；可恢复的模型请求错误才切换备用   |
| `tools / skills / mcpServers` | 合并成可调用工具；重名直接拒绝                       |
| `subAgents`                   | 注册能力目录；模型运行时可调用一个、多次或并行委派   |
| `inputSchema / outputSchema`  | 输入先校验；最终输出转 JSON 再校验；不符合就失败     |
| `limits`                      | 父子共享预算；等待用户单独计时                       |
| `policy`                      | 每次工具执行前查允许列表与可信宿主权限               |
| `onEvent`                     | 宿主观察开始、模型尝试、工具、等待、完成、失败和取消 |

`policy.authorize` 是宿主程序函数，不能让模型自己返回“我有权限”来替代。根 Agent 的允许列表会约束整棵调用树，因此列清单时也要包含允许的子代理工具。Skills 文本里的要求不能扩大这些权限。

这版没有实现写操作审批与业务幂等。如果接入写工具，需先按[设计方案](../设计方案.md)建立审批与幂等节点，再启用工具。普通澄清问题的回答不应直接被当作所有写操作的授权。

## 3. 初始化子代理与独立 Agent

文件：`10-agent.mjs`。本例用计算子代理和报告主代理，主代理可以向用户询问报告类型。

<!-- file: 10-agent.mjs -->

```javascript
import { fileURLToPath } from 'node:url'
import { z } from 'zod'
import { createLearningAgent } from './common/agent.mjs'
import { readModelSettings } from './common/model.mjs'
import { mathTools } from './common/math-tools.mjs'
import { answerInTerminal } from './common/terminal.mjs'

const context = { tenantId: 'demo-tenant', userId: 'demo-user' }
const models = {
  primary: readModelSettings('openai'),
  fallbacks: [readModelSettings('anthropic')],
}
const calculator = await createLearningAgent({
  id: 'calculator',
```

## 4. 子代理如何等待和通信

`delegate_calculator` 的工具函数 `await child.invokeFromParent(...)`，子任务完成后才把结果作为 ToolMessage 交回父模型。因此父模型自然获得结果，再决定下一步。

父模型同一轮提出多个独立的委派工具调用时，第七课的图用 Send 为每次调用建立独立工具任务，等待汇合后再回到父模型；如果 B 的输入依赖 A，就让父模型先拿到 A 的工具结果，再提出 B。并行来自模型实际提出的多个工具调用，也可以像第九课那样由确定的图分发，不能假设模型每次都会并行。

这套教学封装没有单独的 taskId 查询／邮箱服务。第九课的 Send 和本课的工具等待已经覆盖“动态启动并等结果”；跨进程消息、子任务独立重试和持久任务表留在正式运行时设计中。

`invokeFromParent` 是封装内部入口，沿用父运行的检查点、预算、身份和取消信号。独立 `run` 会创建自己的执行预算和会话。不要从前端传 executionId、depth 或图 config。

## 5. 事件、取消与资源释放

- `onEvent` 适合刷新状态、写脱敏日志；返回的 Promise 不会被等待，需要可靠异步写入时由宿主自己的队列承接。
- token 文本流仍使用第二／七课的模型或图 streaming API。本课事件回调提供执行进度，不自动把 token 改成页面 SSE。
- `getRun({ runId, context })` 用于本进程状态查询。
- `await agent.cancel({ runId, context })` 取消原运行；`run.started` 事件中的 executionId 就是该 runId，可让宿主及时记录它。
- 外部 AbortSignal 也可以传给 `run`；`close` 取消自己的活跃运行并关闭自己的 MCP。
- 子 Agent 被父 Agent 借用，关闭顺序为父 → 子，避免其他父实例还在使用它时被提前释放。

同步异常和 Promise 拒绝均被隔离，不改变运行结果；真正的异步持久审计需要单独的队列与失败策略，不能靠这个观察回调保证落盘。

失败或取消后，该教学实例拒绝在相同 thread 上继续，避免未配对的工具调用污染后续消息；改用新 thread。完成后可以在原 thread 开下一轮。运行记录和 MemorySaver 都只存在内存且没有 TTL；长时间服务必须补上持久化、保留期和清理接口。

## 观察、练习与排错

1. 先关闭 Skills、MCP 和子代理，只保留最小聊天，核对第二课的调用过程。
2. 打开计算子代理，观察 `task.started → 子模型／工具 → task.completed`，父模型在工具结果后继续。
3. 同一轮委派两次计算，将 `maxTasks` 设为 1，观察任务数限制；恢复同一委派不会重新增加任务计数。
4. 让子代理调用 ask_user，回答后应恢复同一个父 run；它的 `agentId` 显示提问来源。
5. 使用错误选项 ID 恢复，应在继续图之前被拒绝；换 userId 查询／恢复／取消应拒绝。
6. 将 `maxSteps` 调小测试整树共享限制；将 `maxDepth` 设为 0 阻止所有委派。
7. 开始耗时运行后从宿主取消，确认模型／子图收到取消。工具也要主动支持传入信号；信号不能强制撤销忽略取消的远端业务。
8. 给 outputSchema 故意不匹配的字段，确认最终状态是 failed；不要把 schema 当成给模型看的说明而不做验证。
9. 故意重复工具名，初始化应失败，并释放已建立的 MCP 连接。
10. 断开主模型服务，验证只对可恢复请求错误使用备用；401 或参数错误应直接失败。

完成标准：你能从初始化到 run、waiting_input、resume、终态和 close，解释每一步由谁持有状态，以及父子代理为什么可以用同一套定义。
