# 第八课：AI 提问、候选选项与暂停续接

状态：完整教学资料。前置：[第七课](./07.会话编排.md)。[返回课程入口](../学习教程.md)。

## 目标

当“生成本月报告”存在几个合理理解时，AI 给出问题和候选项，让用户选或补充。等待期间不持续请求模型；回答后接着原来的执行，保留已经完成的结果。

这叫执行中的澄清交互。它与 AbortSignal 取消任务、token 流式输出、写入操作确认是不同能力。

## 1. 定义结构化问题和回答

文件：`common/interaction.mjs`，相对于 `scripts/agent-learning/`。

<!-- file: common/interaction.mjs -->

```javascript
import { tool } from '@langchain/core/tools'
import { interrupt } from '@langchain/langgraph'
import { z } from 'zod'

export const questionSchema = z.object({
  question: z.string().min(1).max(500),
  options: z
    .array(
      z.object({
        id: z.string().regex(/^[a-zA-Z0-9_-]+$/),
        label: z.string().min(1).max(100),
      }),
    )
    .min(2)
    .max(5),
  allowText: z.boolean().default(true),
})

const answerSchema = z
  .object({
    optionId: z.string().optional(),
    text: z.string().trim().max(2000).optional(),
  })
  .strict()

/** 同时供宿主与工具校验，拒绝不存在的选项和未经允许的文字答案。 */
export function validateAnswer({ question, answer }) {
  const value = answerSchema.parse(answer)
  const selected = question.options.find((item) => item.id === value.optionId)
  if (value.optionId && !selected) throw new Error('选项不存在')
  if (value.text && !question.allowText) throw new Error('此问题不接受文字回答')
  if (!selected && !value.text) throw new Error('请选择选项或填写回答')
  return {
    ...(selected ? { optionId: selected.id, optionLabel: selected.label } : {}),
    ...(value.text ? { text: value.text } : {}),
  }
}

/** 生成可暂停的澄清工具；该工具只能在支持检查点的图调用中执行。 */
export function createAskUserTool(agentId = 'assistant') {
  return tool(
    async (input) => {
      const question = questionSchema.parse(input)
      if (new Set(question.options.map((item) => item.id)).size !== question.options.length) {
        throw new Error('问题选项 ID 重复')
      }
      const answer = interrupt({ kind: 'question', agentId, ...question })
      return JSON.stringify(validateAnswer({ question, answer }))
    },
    {
      name: 'ask_user',
      description: '缺少影响任务的关键信息时提问，提供 2 到 5 个候选选项，等待用户回答。',
      schema: questionSchema,
    },
  )
}
```

`interrupt()` 会把问题保存进检查点并交回宿主，不是在工具内部开一个持续请求模型的循环。它使用框架的控制流机制，不能被普通 try/catch 当作工具异常吞掉。

## 2. 用终端模拟前端选项组件

文件：`common/terminal.mjs`。

<!-- file: common/terminal.mjs -->

```javascript
import { createInterface } from 'node:readline/promises'
import { stdin, stdout } from 'node:process'
import { validateAnswer } from './interaction.mjs'

/** 终端仅作为宿主演示；真实产品用选项组件收集同样的结构化答案。 */
export async function answerInTerminal(question) {
  const reader = createInterface({ input: stdin, output: stdout })
  try {
    console.log('\n[' + question.agentId + '] ' + question.question)
    question.options.forEach((item) => console.log(item.id + '：' + item.label))
    while (true) {
      const raw = (await reader.question('输入选项 ID 或自己的说明：')).trim()
      const selected = question.options.find((item) => item.id === raw)
      const answer = selected ? { optionId: selected.id } : { text: raw }
      try {
        validateAnswer({ question, answer })
        return answer
      } catch (error) {
        console.log(error.message)
      }
    }
  } finally {
    reader.close()
  }
}
```

## 3. 暂停后用相同 thread 恢复

文件：`08-interrupt.mjs`。

<!-- file: 08-interrupt.mjs -->

```javascript
import { MemorySaver, Command } from '@langchain/langgraph'
import { createModel } from './common/model.mjs'
import { buildAgentGraph } from './common/graph.mjs'
import { createAskUserTool } from './common/interaction.mjs'
import { answerInTerminal } from './common/terminal.mjs'
import { messageText } from './common/text.mjs'

const graph = buildAgentGraph({
  models: [createModel()],
  tools: [createAskUserTool('report-helper')],
  systemPrompt:
    '你是报告助手。报告类型缺失时必须调用 ask_user，收到答案后再整理。未知数据写待补充。',
  checkpointer: new MemorySaver(),
})
const config = { configurable: { thread_id: 'interrupt-demo' }, recursionLimit: 30 }

/** 每次活跃执行设置请求时限，不让终端等待时间耗尽下一次续接的信号。 */
function execute(input) {
  return graph.invoke(input, { ...config, signal: AbortSignal.timeout(60_000) })
}

let result = await execute({
  messages: [{ role: 'user', content: '帮我生成本月报告。' }],
})
while (result.__interrupt__?.length) {
  const resume = {}
  for (const pending of result.__interrupt__) {
    console.log('交互 ID：', pending.id)
    resume[pending.id] = await answerInTerminal(pending.value)
  }
  result = await execute(new Command({ resume }))
}
console.log(messageText(result.messages.at(-1)))
```

```powershell
vp node --env-file=.env.agent.local scripts/agent-learning/08-interrupt.mjs
```

`Command({ resume })` 的对象把“交互 ID”映射到答案，支持并行子任务产生多个问题。这里不调用新的用户消息来替代 resume，不重新生成整个报告任务。

## 4. 换成页面后如何交互

同一进程内的宿主可以先返回：

```json
{
  "status": "waiting_input",
  "runId": "example-run-id",
  "questions": [
    {
      "interactionId": "example-interaction-id",
      "question": "需要哪种报告？",
      "options": [
        { "id": "sales", "label": "销售报告" },
        { "id": "stock", "label": "库存报告" }
      ],
      "allowText": true
    }
  ]
}
```

这是响应语义示意，不是已新增的项目 HTTP 契约。界面展示选项、收集答案；后端校验运行归属、交互 ID、选项和有效期，再执行 resume。浏览器连接断开不必一直占着一个 HTTP 请求，进程内的待答状态仍可查询。

推荐项可以默认高亮，但没有提交就不算回答。问题超时也不能自动替用户选。

## 5. 恢复时的重放边界

恢复会重新进入发生中断的节点。`interrupt` 之前的普通代码可能再次执行；如果同一个工具节点并行执行多个工具，其他工具也可能因该节点重试而重放。

本课程工具都是读取或纯计算。真实发送邮件、扣款、写数据库等操作需使用独立节点、幂等键及执行记录，并将确认放在写入前。不能因为“有检查点”就承诺任意副作用只执行一次。

## 练习与完成标准

- 选一个候选项，观察原任务继续；再运行一次填写自由文本。
- 提交错误 optionId，宿主应拒绝且保留原待答状态。
- 等待时检查没有持续模型调用；通过第十课的事件和计数进一步观察。
- 比较“暂停等待”“取消结束”“失败”三种状态，不能把 waiting_input 当成功。
- 多个问题同时出现时按各自 ID 回答，不能只取第一项。

完成标准：AI 能生成候选解释，用户决定答案，程序续接同一个 run；暂停不代表释放或销毁 Agent。
