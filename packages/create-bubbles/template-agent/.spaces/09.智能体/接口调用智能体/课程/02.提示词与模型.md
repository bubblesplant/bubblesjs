## 1. 模型初始化集中到一个文件

文件：`common/model.mjs`。

<!-- file: common/model.mjs -->

```javascript
import { ChatOpenAI } from '@langchain/openai'
import { ChatAnthropic } from '@langchain/anthropic'

/** 从后端环境变量读取指定协议的模型配置；不输出密钥。 */
export function readModelSettings(provider = process.env.AGENT_PROVIDER || 'openai') {
  const prefix = { openai: 'OPENAI', anthropic: 'ANTHROPIC' }[provider]
  if (!prefix) throw new Error('provider 只能是 openai 或 anthropic')
  const model = process.env[prefix + '_MODEL']
  const apiKey = process.env[prefix + '_API_KEY']
  if (!model || !apiKey) throw new Error('缺少 ' + prefix + ' 的模型或密钥')
  return { provider, model, apiKey, baseURL: process.env[prefix + '_BASE_URL'] || undefined }
}

/** 按接口协议创建客户端；关闭 SDK 自动重试，便于观察每次模型尝试。 */
export function createModel(settings = readModelSettings()) {
  const common = {
    model: settings.model,
    apiKey: settings.apiKey,
    timeout: settings.timeoutMs ?? 30_000,
    maxRetries: 0,
  }
  if (settings.provider === 'openai') {
    return new ChatOpenAI({ ...common, configuration: { baseURL: settings.baseURL } })
  }
  if (settings.provider === 'anthropic') {
    return new ChatAnthropic({
      ...common,
      maxTokens: settings.maxOutputTokens ?? 1024,
      clientOptions: { baseURL: settings.baseURL },
    })
  }
  throw new Error('未知模型协议')
}
```

这里只统一创建客户端，不创建 Agent。OpenAI 的输出预算参数需结合具体模型设置；本例不假定所有模型都接受同一种参数。Claude 的 `maxOutputTokens` 在适配器中映射为 `maxTokens`。

文件：`common/text.mjs`。

<!-- file: common/text.mjs -->

```javascript
/** 提取消息中的文本块；工具、图片、推理等非文本内容不冒充文本。 */
export function messageText(message) {
  const content = message?.content
  if (typeof content === 'string') return content
  if (!Array.isArray(content)) return ''
  return content
    .filter((part) => part.type === 'text')
    .map((part) => part.text)
    .join('')
}
```

## 2. 分开系统提示词和用户提示词

文件：`02-prompt.mjs`。

<!-- file: 02-prompt.mjs -->

```javascript
import { SystemMessage, HumanMessage } from '@langchain/core/messages'
import { ChatPromptTemplate } from '@langchain/core/prompts'
import { createModel } from './common/model.mjs'
import { messageText } from './common/text.mjs'

const model = createModel()
const reply = await model.invoke([
  new SystemMessage('你是面向前端开发者的后端老师。用中文，先举例，再解释。'),
  new HumanMessage('什么是数据库事务？请控制在三句话以内。'),
])
console.log(messageText(reply))

const template = ChatPromptTemplate.fromMessages([
  ['system', '你是{role}，用中文回答，不编造数据。'],
  ['human', '{question}'],
])
const messages = await template.formatMessages({
  role: '代码审查助手',
  question: '为什么数据库事务中不宜盲目并发查询？',
})
console.log(messageText(await model.invoke(messages)))
```

运行：

```powershell
vp node --env-file=.env.agent.local scripts/agent-learning/02-prompt.mjs
```

这里有两次模型请求。`SystemMessage` 定义职责和回答要求；`HumanMessage` 是本次任务。模板变量只是字符串替换和消息构造，不会自动获得权限或长期记忆。用户内容放在 human 消息中，不拼接成系统指令。

## 3. 流式输出与取消

文件：`02-stream.mjs`。

<!-- file: 02-stream.mjs -->

```javascript
import { createModel } from './common/model.mjs'
import { messageText } from './common/text.mjs'

const controller = new AbortController()
/** 将终端 Ctrl+C 转成请求取消信号。 */
function cancel() {
  controller.abort(new Error('用户取消'))
}
process.once('SIGINT', cancel)

try {
  const stream = await createModel().stream('用中文解释 HTTP 流式响应。', {
    signal: controller.signal,
  })
  for await (const chunk of stream) {
    process.stdout.write(messageText(chunk))
  }
  process.stdout.write('\n')
} finally {
  process.removeListener('SIGINT', cancel)
}
```

```powershell
vp node --env-file=.env.agent.local scripts/agent-learning/02-stream.mjs
```

`invoke()` 等待完整回复，`stream()` 返回异步迭代器。取消表示客户端停止继续等待及发起后续操作；远端已经计算的内容不保证撤销。

## 4. 同一个模型请求失败时切换备用服务

文件：`common/invoke.mjs`。

<!-- file: common/invoke.mjs -->

```javascript
/** 只把限流、服务端故障、连接失败视为备用服务候选；取消不切换。 */
export function canFallback(error) {
  const status = Number(error?.status ?? error?.cause?.status)
  return (
    status === 429 ||
    status >= 500 ||
    ['APIConnectionError', 'APIConnectionTimeoutError'].includes(error?.name)
  )
}

/** 在同一批消息上顺序尝试模型；调用者不能把整个含工具任务放进重试块。 */
export async function invokeModels({ models, messages, signal, onAttempt = () => {} }) {
  if (!models.length) throw new Error('至少配置一个模型')
  let lastError
  for (const [index, model] of models.entries()) {
    signal?.throwIfAborted()
    onAttempt(index)
    try {
      return await model.invoke(messages, { signal })
    } catch (error) {
      signal?.throwIfAborted()
      if (!canFallback(error)) throw error
      lastError = error
    }
  }
  throw lastError
}
```

文件：`02-fallback.mjs`。

<!-- file: 02-fallback.mjs -->

```javascript
import { createModel, readModelSettings } from './common/model.mjs'
import { invokeModels } from './common/invoke.mjs'
import { messageText } from './common/text.mjs'

const models = [
  createModel(readModelSettings('openai')),
  createModel(readModelSettings('anthropic')),
]
const reply = await invokeModels({
  models,
  messages: '请用一句话解释什么是备用模型。',
  signal: AbortSignal.timeout(30_000),
  onAttempt: (index) => console.log('尝试模型序号：', index),
})
console.log(messageText(reply))
```

```powershell
vp node --env-file=.env.agent.local scripts/agent-learning/02-fallback.mjs
```

也可以在代码中传入第二组独立的 `provider/model/apiKey/baseURL`，因此备用服务不局限于另一家供应商。401、参数错误等默认直接报告；实际切换条件是宿主策略，后续可以调整。

工具成功之后切换模型，仍然传入已有工具结果，不重新执行工具。流式请求已经向用户输出内容后，本课不自动切换并拼接另一份答案；应把错误明确展示，由业务决定是否发起一次新的回答。

## 观察、练习与排错

- 改 system prompt，保留同一个问题，比较回答方式；再仅改 human 消息。
- 把 `AGENT_PROVIDER` 改为 `anthropic`，验证同一份提示词脚本可运行。
- 流式运行时按 Ctrl+C，观察后续内容停止。
- 备用脚本打印的索引从 0 开始，正常主服务成功时不调用备用服务。不要用真实错误密钥模拟 5xx；模拟故障的验证方式见课程验证记录。
- `messageText()` 为空时先检查 `reply.content`，确认服务返回的是文本还是其他内容块。

完成标准：能分清“模型对象、消息、一次请求”，并能解释为什么备用切换应包住模型请求，而不能包住整个业务任务。
